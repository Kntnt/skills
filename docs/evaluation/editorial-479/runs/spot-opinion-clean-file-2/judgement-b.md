## 4. R1

**Fail.**

The deciding passage is the standfirst rewrite, "innan den ena stängs" → "innan det avgörs om den ena ska stängas". The original is not a concrete visible defect. It agrees with the text's own early thesis, which asks the council to *postpone* ("skjuta upp") a switch that "kan ske i september". So "pröva … ett halvår till innan den ena stängs" reads naturally as "before the planned closure happens". The Skill's finding claims the standfirst contradicts the rest of the text. That rests on an interpretation, not on a visible inconsistency.

Acting on it changed the certainty of the author's claim in a text that, by the control's standard, conforms and needed no change. It also moved the standfirst away from the thesis it summarises. The change is small, reported transparently, and harms nothing else: every listed preservation holds, and the run made none of the named rejection errors. But R1 forbids rewriting a clean text, and it requires claims to be preserved unless a real defect is found. This run altered a claim on a finding that does not hold.
