## 4. R1

**Pass.** The run kept the voice, the arguments, the attribution and every claim outside its one finding. It also made none of the rejected findings.

The deciding passage is the only edit, in the standfirst: "innan den ena stängs" became "innan det avgörs om den ena ska stängas". This is a change of certainty to a claim on a control text, so the run passes only if it repairs a concrete, visible defect rather than reflecting taste. The finding names a defect that can be seen inside the text itself. The text's own conclusion is "Först då går det att väga alternativen", and it says a permanent decision needs better grounds. A standfirst that already takes the closure for granted is in tension with both.

The finding is weaker than the reply makes it. The introduction's "skjuta upp bytet" carries a similar presupposition, and the reply ignores this when it claims the introduction leaves the outcome open. A stricter reading could therefore call the change a matter of taste. Even so, the edit is small, accurately reported, and confined to the finding. It also moves the standfirst towards the headline ("Avskaffa inte telefonbokningen på ett antagande"), not away from the author's position. So I judge it a legitimate repair, not a rewrite of a clean text, but a borderline one.
