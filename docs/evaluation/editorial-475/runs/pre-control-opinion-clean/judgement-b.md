## 4. R1

**Fail.** The fail is narrow. Every passage the standard names is preserved, the voice is intact, and none of the named traps was taken. The deciding passage is the Skill's one finding, together with the rewrite it produced: "Inledningsstycket nämnde inte vilka bokningsvägarna var … Inledningsstycket säger nu 'båda bokningsvägarna, digital bokning och telefonbokning,'". On a text the standard calls conformant, the Skill claimed an anatomy defect. The defect is not visible: the referent is given in the same paragraph ("enbart digital bokning") and in the heading and standfirst directly above ("telefonbokningen"). Acting on that finding, it inserted words into a clean text, and R1 says "Clean texts may not be rewritten to satisfy taste." The change was reported openly and alters no claim, so it does no damage. It is still a rewrite that the standard does not allow.
