# Judgement a

## 1. Differences

There is one difference between `work/input.md` and `work/output.md`. The two files match in everything else, including the byline, the standfirst, both subheadings, every paragraph and the formatting. The input has no frontmatter, and the output adds none.

- Headline. Before: `# Mätförsöket i Björkskolan visar när, inte varför`. After: `# Björkskolans mätvärden bör kopplas till användningstiderna`. Class: a change of taste on a clean text, and it also changes what a claim says.
  - **Meaning:** the headline used to state the result, "shows when, not why". It now gives a recommendation, "should be linked to the times of use".
  - **Attribution:** in the body the recommendation is Elin Rask's ("Rask rekommenderar …"), plus the ending's instruction. The headline now puts it forward in the article's own voice, without Rask's name.
  - **Chronology:** the body ties the recommendation to a point in time, "innan styrningen ändras" / "innan nästa givare sätts upp". The headline drops that condition.
  - **Scope:** the limitation, that the measurements do not explain why the air was cold, is gone from the headline.

## 4. R1

**Fail.** The input is a clean text that conforms to the anatomy. The Skill rewrote its headline because the headline and the standfirst make the same point: "Den som läste rubriken och sedan ingressen fick samma poäng två gånger i rad." That is not a concrete, visible defect. A headline and a standfirst that both carry the result is the anatomy working as intended, so the rewrite is a change of taste, which R1 forbids for clean texts.

The rewrite also changed a claim outside any legitimate finding:

- **Before:** "Mätförsöket i Björkskolan visar när, inte varför"
- **After:** "Björkskolans mätvärden bör kopplas till användningstiderna"

The change swaps a finding for Rask's recommendation, moves that recommendation into the article's own voice, and drops the condition "innan styrningen ändras". The reply reports most of this honestly, but reporting a change does not make an unwarranted rewrite of a clean text legitimate.
