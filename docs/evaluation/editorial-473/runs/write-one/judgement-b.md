## 2. P1, the order

Pass. The parts run headline, summary, first quotation, body, background, links, contact, description, which is the standard's order. Every part the material supplies is present. The material gives one quotation, so there is no second quotation to place. The material gives no publication time; the date "3 juni 2027" is the date of the inauguration, not a time from which the release may be published, so no line above the headline is owed. The front matter before the headline is metadata and carries no release content, so it does not break the order. The deciding passage is the sequence "…7,5 gigawattimmar el om året." followed directly by "– Solparken visar …", then "Enligt bolagets egen beräkning …", then "Grustäkten vid Kvarnbacken avvecklades 2019."

## 3. Q1, quotations only from the material

Pass. The one quotation is the material's, word for word: material "Solparken visar att en gammal grustäkt kan göra nytta igen, och vi vill att elen som används i Tallmora också ska produceras här."; draft "– Solparken visar att en gammal grustäkt kan göra nytta igen, och vi vill att elen som används i Tallmora också ska produceras här, säger Maria Ekholm, vd för Tallmora Energi."
