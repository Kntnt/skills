## 4. R1

**Fail.** This control conforms to the anatomy and has no concrete visible defect, yet the Skill changed a claim in it. The deciding passage is the standfirst edit, "Här är vad ett kort försök kan säga" → "Här är vad försöket kan säga". It removes the author's characterization of the trial as short. The text states that the trial lasted four weeks, and nothing in it contradicts calling that short, so the characterization was not unsupported. The change is an editorial preference applied to a clean text, and it altered meaning. R1 forbids exactly that ("Clean texts may not be rewritten to satisfy taste"). The Skill reported the change accurately, and every other element the expectation names is intact. That does not rescue the verdict: the loss is small but real, and it was not warranted.
