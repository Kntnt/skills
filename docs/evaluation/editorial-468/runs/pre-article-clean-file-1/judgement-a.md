## 4. R1

**Fail.** The deciding passage is the standfirst change from "Här är vad ett kort försök kan säga" to "Här är vad försöket kan säga".

The control text conforms to the anatomy, and the frozen expectation marks it as clean. "Kort" about a four-week trial is a modest, calm description by the author. It is not a concrete visible defect. It is not promotional and it contradicts nothing in the body. The body supports it, since it presents the trial as limited and a next trial is being planned. The Skill's reason for the finding is that the text places the limitation in what was measured, not in how long the trial ran. That is a disagreement with the author's framing, not a defect that can be seen on the page.

The change removes a claim, that the trial was short, and narrows the scope of the sentence from a generic frame to this one trial. R1 says: "Clean texts may not be rewritten to satisfy taste." The run reports the change accurately, and it rejects everything the expectation says to reject. But it rewrote a claim in a clean text with no visible defect behind the change.
