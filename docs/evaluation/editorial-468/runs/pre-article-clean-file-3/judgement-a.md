# Judgement a

## 1. Differences

`work/input.md` and `work/output.md` differ in one place only. Frontmatter: neither file has any. Formatting: the headline, bold standfirst, byline, headings, italic report title and quotation marks are identical.

- Standfirst, third sentence. Before: "Här är vad ett kort försök kan säga, och vad som behövs för att komma vidare." After: "Här är vad försöket kan säga, och vad som behövs för att komma vidare." Class: a change to what a claim says, in **meaning** and **scope**. The text no longer calls the trial short (meaning). The sentence moves from what a short trial in general can say to what this particular trial can say (scope). This is not the repair of a visible defect: "kort" rests on a basis the standfirst gives itself ("Fyra veckors mätningar"), and nothing else in the text contradicts it.

## 4. R1

**Fail.**

The deciding passage is the finding "”Här är vad ett kort försök kan säga …” kallade försöket kort utan att texten ger något att jämföra med … Ordet antydde att ett längre försök med samma givare skulle räcka", together with the edit it produced ("ett kort försök" → "försöket").

The frozen expectation marks this as a text that conforms, so it is a clean control. R1 says "Clean texts may not be rewritten to satisfy taste." "Kort" is the writer's own characterisation of a four-week trial, and the same sentence states that duration. The suggestion that a longer trial would be enough is the Skill's inference, not something the text visibly says. The text in fact rules it out under "Nästa försök behöver mer än givare". So the edit removes a working claim and widens nothing into a defect: it rewrites a clean standfirst for taste and changes what the claim says (meaning, scope).

Everything else the expectation names is preserved, none of the named rejections was committed, and the edit is reported accurately. The failure is this one unwarranted rewrite of a clean text.
