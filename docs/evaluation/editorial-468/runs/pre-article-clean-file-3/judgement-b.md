# Judgement b

## 1. Differences

There is one difference between `work/input.md` and `work/output.md`. There is no frontmatter in either file. The headline, byline, lead, subheadings, quotation, body paragraphs, ending and all formatting (bold standfirst, italic report title, `##` headings, typographic quotation marks) are identical.

- Standfirst, third sentence. Before: "Här är vad **ett kort försök** kan säga, och vad som behövs för att komma vidare." After: "Här är vad **försöket** kan säga, och vad som behövs för att komma vidare." Class: a change to what a claim says. It changes **meaning**, because it removes the text's own description of the trial as short. It also changes **scope**, because the generic "a short trial" becomes "the trial", the specific one. The input supports "kort": the sentence right before it says "Fyra veckors mätningar", and the text's whole point is what a limited trial can and cannot show. So the edit does not repair a visible defect. It is an editorial judgement, that is, a change of taste that alters a claim.
