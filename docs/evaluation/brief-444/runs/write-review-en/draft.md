# North Lantern Workshop introduces paper tool bookings

North Lantern Workshop will introduce a paper tool booking list on 5 October 2026.

How can members reserve a tool without a computer? From 5 October 2026, members reserve a tool by writing their name and the tool on the list at the desk.
