# Den nya bokningslistan

Från den 5 oktober 2026 bokar medlemmarna i Lindö Verktygsrum låneverktyg på en papperslista vid disken. Bokningen görs utan dator.

Så hjälper du som volontär en medlem att boka:

1. Visa var listan finns vid disken.
2. Be medlemmen skriva sitt namn och vilket verktyg bokningen gäller på listan.

Visa nästa medlem som vill boka ett verktyg till listan.
