# Visa medlemmen bokningslistan

Från den 5 oktober 2026 bokar medlemmar i Alder Tool Room verktyg på en papperslista vid utlåningsdisken. Medlemmen skriver sitt namn och vilket verktyg bokningen gäller på listan.

Så visar du som volontär hur bokningen går till:

1. Visa nästa medlem papperslistan vid disken.
2. Förklara att medlemmen bokar ett verktyg genom att skriva sitt namn och verktyget på listan.
