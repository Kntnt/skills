## 4. R1

**Fail.**

The deciding passage is finding 1 and the rewrite it produced. Input: "En temperaturgivare mäter luften där den sitter. Det gör placeringen viktig när fastighetskontoret ska tolka fyra veckors mätningar …". Output: "… Det avgränsar vad fastighetskontoret kan läsa ut av fyra veckors mätningar …".

The finding says the opening paragraph made a promise the body never kept, because the body never says where the sensors sat. The sentence makes no such promise. It is a short, valid inference from the sentence before it: a sensor measures where it sits, so placement matters for interpretation. The body is consistent with it. The values say when the air was cold but not how the room felt, and the next trial keeps "likadant placerade givare". No reader is left waiting for a promised discussion. There is no concrete visible defect here, only the reviewer's preference about how the paragraph sets up the body.

The frozen expectation marks this text as conforming and clean. R1 says that "clean texts may not be rewritten to satisfy taste", and the change is not a mechanical correction that the proofreading pass would own. The run therefore rewrote a clean text on taste. In doing so it removed a working claim, which its own reply records as lost ("det uttryckliga påståendet att placeringen är viktig för tolkningen"), and changed that claim's meaning. Reporting the change accurately and limiting it to one sentence does not cure the loss.
