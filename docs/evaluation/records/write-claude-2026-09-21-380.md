Each run's working directory held `source.md` and an empty `scratch/` and nothing else. No Codex Harness and no GPT model was started, controlled or invoked from this session, and no GPT-family record was opened before every fixture here was judged.

Three statements beyond the invocation went into each turn, and they are the evaluator's rather than the Skill's: copy the source-check scratch to `evidence/` before it is removed; save the complete user-facing reply verbatim to `response.md`; and, where the Skill tells the run to ask the user something, state the question in the final reply and stop, because nobody is available to answer. No run's `response.md` write was refused, so all eight are the runs' own and are declared evaluator additions rather than Skill side effects, as is `evidence/`.

Counted requirements are counted by script. `skills/kntnt/library/scripts/article_anatomy.py` as `8a37e57e` holds it — byte-identical to the file at `9a29bad3` that #386 measured with — was run by the evaluator from its own copy and never from the staged install, on each delivered draft; the JSON sits beside the run as `anatomy-delivered.json`, and its figures are the evidence for every counted line below.
