Draft: `prose.md` (complete, incl. frontmatter, headline, standfirst, byline, subheadings)
Material: `material.md` (brief + Underlag + Boundaries)

Resolved language: Swedish (sv). Material language: Swedish. No translation of quoted speech occurs anywhere in the draft, and the draft contains no direct quotation in quotation marks; the translation half of this check is therefore vacuous (see §4).

## 3. Cases tested in both directions and set aside

Each entry names the concrete case that would have to stand for the pair to diverge, then the supplied statement that excludes it. None of these is reported as a finding.

**3.1 Standfirst “räknar bokningar, inte människor” vs “Rapporten räknar bokningar, inte unika personer.”**
Case in the draft's disfavour: the report also carries a non-unique headcount (say, visitors per lokal), so it counts bookings *and* people, though still not unique persons — the source holds, the draft's “inte människor” fails.
Excluded by: “Rapporten räknar bokningar, inte unika personer.” The supplied statement names what the report's counts are counts of — bookings — and the only other counting it reports is the 96/24 split of those same bookings by channel. A parallel people-count is not something the material leaves open; it is something the material's account of the report has no room for. The draft's compression also states the precise form verbatim eight lines later (P2) and spends its next paragraph unpacking it (P3), so no reader takes “inte människor” as a claim about a different tally. Defensible as written; reporting it would be a preference about compression, not a defect.

**3.2 “Därför säger den ingenting om hur stor andel …” vs “Telefonbokningarna kan därför inte användas för att säga hur stor andel …”**
Case in the draft's disfavour: the phone figures cannot bear the share, yet the report says something about the share by some other route — an external statistic, a staff note — so the source holds and the draft's “säger ingenting” fails.
Excluded by: “Den mäter inte ålder, funktionsförmåga eller digital vana.” A *share of residents who cannot book digitally* can only be stated from measurement of exactly those variables across residents; the supplied statement denies the report all three. The residual case — the report quoting some outside figure — would not be the report saying what share of Lervik's residents cannot book digitally, and the material fixes the report's scope as “ett åtta veckor långt försök i två lokaler”.
