## 3. Editorial question (not a finding, no repair proposed)

**Line 20 — "En givare mäter temperaturen där den sitter, och den mäter luft."**
The first clause is verbatim from the material. The second clause continues the material's generic singular while the support for it — "försöket mätte bara lufttemperatur" — is stated about this trial. A case can be described in which a sensor does not measure air alone: a globe sensor for operative temperature is also "en givare", and the material does not exclude one being used, for instance in the November trial. Against that: the material itself introduces operative temperature as "ett annat mått", conceding that a different measure calls for something other than the instrument under discussion; the draft states the trial-specific fact explicitly in the very next sentence ("Försöket mätte bara lufttemperatur"); and the brief asks for concepts to be explained before use without discarding the technique, which is what the generic phrasing does. Read as an ordinary reader would in a section that has just described this trial's wall-mounted sensors, "en givare" names the instrument under discussion, not every temperature sensor that exists. On that reading the passage is defensible as written, so it is recorded here as a question of editorial scope rather than as a defect. No repair is proposed; naming the trial's sensors in the second clause would close the question without touching anything else.
