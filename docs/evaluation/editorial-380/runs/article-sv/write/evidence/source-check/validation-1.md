Passage: "En givare mäter temperaturen där den sitter, och den mäter luft."

The checker raised, and itself set aside, a scope question: the clause continues
the material's generic singular while its support — "försöket mätte bara
lufttemperatur" — is stated about this trial.

Disposition: accepted as written; no change made, so no second comparison is
triggered.

Evidence: read in its full context the sentence stands in a paragraph that has
just described this trial's six wall-mounted sensors, and its next two sentences
contrast the measure with operative temperature and then state "Försöket mätte
bara lufttemperatur" outright. An ordinary reader takes "den" as the sensor
under discussion, not as every temperature sensor that exists. The generic
reading on which a globe sensor would falsify the clause is a merely conceivable
stronger reading, which does not establish a defect. The checker proposed no
repair and judged the passage defensible; that judgement is confirmed here on
