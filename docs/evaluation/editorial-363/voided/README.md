# Attempts that were made and do not count

Ten `r`-arm attempts, preserved whole and counted against nothing. They are kept because the ticket says to preserve every run, and because the reason they are void is itself a finding.

**Why they are void.** Both editorial Skills declare `kntnt.capabilities: "subagents"`, and both require one: Write to start the fresh source checker, Redline to start the fresh correction agent its step 7 describes. The session that resumed this ticket is itself a subagent of an orchestrating session, and a subagent of that harness has no agent-spawning tool at all. Write's step 1 caught this and stopped correctly — that stop is `r-case-study-sv-r2-response.md` here, and it is the whole of what that attempt produced. Redline has no equivalent step, so Redline attempts in the same seat ran to completion and reported correction rounds whose fresh seat cannot be established. That gap is [#394](https://github.com/Kntnt/skills/issues/394).

Two of these attempts finished after a session-harness run had already started in the same directory, so which artefacts belonged to which run could not be established for them either. They are the two Write attempts under `subagent-seat/` below: their `finished.txt` markers read `22:23:18Z` and `22:10:31Z`, and the session runs in `../runs/r/case-study-sv-r1` and `../runs/r/case-study-sv-r3` had started at `22:08:49Z` in those same directories. The seven Redline attempts are not in that position — every one of them finished by `22:07:05Z`, before any session run started. Where provenance could not be established the attempt was treated as not completed and the row was re-run, which is what the ticket instructs.

**Ten attempts were re-run as fresh top-level Claude Code sessions; seven `r`-arm rows were not, and are still the subagent-seat runs.** An earlier version of this file said every `r`-arm row was re-run, and that is not true. The rows re-run are the seven Redline rows listed below and the three `case-study-sv` Write rows, and those replacements are the ones under [`../runs/r/`](../runs/r/) bearing `started.txt` markers in the `22:08:49Z` wave. The rows **not** re-run are `sv-control-r1` and `r2`, `sv-artefact-r1` and `r2`, `ellipsis-sv-r1` and `r2`, and `en-positive-r1`: their markers run from `17:30:54Z` to `17:31:37Z`, they were dispatched as subagents in the pattern the `b` and `c` waves carry, and they stand in `../runs/r/` as they were made. So the seat question [#394](https://github.com/Kntnt/skills/issues/394) records is open for those seven exactly as it is for the attempts kept here. [`../results.md`](../results.md) says what that costs; in short, nothing that decides the ticket, because the decision rests on the `b` and `c` arms.
