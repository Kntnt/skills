## 2. Quoted speech

1. **”– Vi körde parallellt i sex veckor. Sedan gick lagret över, och först då såg vi hur mycket som hade legat i pärmar, säger Ove Ranneby.”**
   - **Wording:** returns identical, dash, punctuation and attribution included.
   - **One pass?** Yes. *Körde parallellt* is the ordinary Swedish for running two systems side by side, and the bridge above has just described the double registration that makes it concrete. *Gick lagret över* is everyday metonymy — the warehouse for the people in it — a figure Swedish uses of itself, so it reads at speed however literal-minded a parse would make it look. *Hur mycket som hade legat i pärmar* is plain Swedish for records kept on paper, and the opening paragraph has already set up that the balance lived outside any system. No stopping point; nothing to supply from outside the text.
   - Unchanged and unobstructed, so neither the reported-change nor the unresolved-obstacle test applies. Note that the repair at difference 1 removed the very words the bridge shared with this quotation, which leaves the quotation carrying *sex veckor* first in the body's own prose rather than second.

2. **”– Jag skulle göra om det. Att se samma saldo för båda lagren hjälper oss, men jag skulle ta en artikelgrupp i taget, säger Ranneby.”**
   - **Wording:** returns identical.

No stopping point.
   - Unchanged and unobstructed.
