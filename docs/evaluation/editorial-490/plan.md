Read these from the native trace and captured files, not the run's self-report. An unavailable trace segment is explicitly missing, never reconstructed as an observed statement. A missing state required to answer a criterion makes that criterion skipped and the evaluation incomplete; it cannot establish non-reproduction or authorise candidate wording. Stop and record the operational boundary if complete mandatory states cannot be preserved by the native runner.

- **T1 — native target miss.** A false whole-text exclusivity/absence assertion about the received text was already in the draft, the checker failed to name that falsehood, and the terminal reply still carries it. A reworded terminal statement counts if the same falsehood was present in the draft. The contradicting passage and the scope/predicate actually asserted must be recorded.
