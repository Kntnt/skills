Control: a Swedish opinion piece (debattartikel) about Lervik's phone booking. The frozen expectation says the text conforms to the anatomy. It lists nothing to detect.

## 1. Differences

The text has no frontmatter, and the frontmatter did not change. The headline, standfirst, byline, headings (except D3), bold formatting and paragraph breaks are unchanged. No mechanical (proofreading) corrections were made.

- **D1, opening paragraph, first sentence.**
  Before: "Kommunstyrelsen i Lervik bör skjuta upp bytet till enbart digital bokning av föreningslokaler."
  After: "Kommunstyrelsen i Lervik bör skjuta upp bytet till enbart digital bokning av föreningslokaler, ett byte som kan ske i september."
  Class: a change to a claim, **chronology**. The body now carries a date that only the standfirst carried before. The certainty ("kan") matches the standfirst ("I september kan telefonbokningen ... försvinna"), so the meaning is not new to the article. I count it as a defensible repair of a visible defect: the closing sentence's "september" had no antecedent in the body.
- **D2, section "Bokningar är inte samma sak som personer", second paragraph.**
  Before: "En bokning är en händelse, inte en invånare. Den skillnaden avgör vad siffrorna kan användas till."
  After: the same two sentences plus "Att de räcker som underlag för att avskaffa telefonbokningen är ett antagande."
  Class: a change to what the text claims, **meaning**. A new argumentative sentence is added in the author's name. It decides which assumption the headline and the heading "Besluta om försöket, inte om antagandet" refer to. The text left that to inference. The body's own nearest candidate is a different one: "hur många som skulle klara sig utan telefonbokning", that is, the assumption that people can manage without phone booking. This is not a repair of a concrete visible defect. The headline's "ett antagande" is a working antecedent for the heading's "antagandet".
- **D3, subheading.**
  Before: "## Mät också arbetet med två kanaler" (33 characters)
  After: "## Mät också arbetet med två bokningsvägar" (39 characters, still within 33–40)
  Class: a change of taste (terminology harmonisation). "Kanaler" is an unambiguous synonym in context. No claim changes.
- **D4, same section, body.**
  Before: "Att behålla två kanaler kostar arbete"
  After: "Att behålla två bokningsvägar kostar arbete"
  Class: a change of taste, the same harmonisation as D3. No claim changes.

## 4. R1

**Fail (narrow).** The run preserves everything the expectation names and makes none of the named mistakes. But on a clean control it adds a new claim in the author's voice that repairs no concrete visible defect. The deciding passage is the added sentence:

> "Att de räcker som underlag för att avskaffa telefonbokningen är ett antagande."

The text already had a working antecedent for "antagandet" in the headline's "ett antagande". The added sentence fixes one interpretation of the assumption in the author's name. That interpretation is not the only one the body supports: the body's "hur många som skulle klara sig utan telefonbokning" points to another. R1 forbids rewriting a clean text for taste and requires claims outside real findings to be preserved. The terminology swap (D3, D4) is taste as well, though harmless.

Mitigating factors: D1 is a defensible repair. Every change is reported, and D2 is flagged for the author's approval.
