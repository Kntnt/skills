```markdown
# Solvikens öppettider

Solvikens läsesal är stängd varje måndag. Besökare kan inte komma in när läsesalen är stängd.

Varje måndag är Solvikens läsesal öppen för besökare mellan klockan 10 och 16. Välkommen in under öppettiden.
```
