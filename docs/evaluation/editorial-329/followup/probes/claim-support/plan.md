# Proposition-level diagnostic

The first candidate source checker missed a repeated coordination/chronology claim in all three US customer cases. Before changing product instructions, replay one complete failed artifact and its source with a neutral proposition-level comparison task, without naming the faulty date or clause. This tests whether explicit source-support accounting reveals a defect that general no-findings comparison missed. The report is diagnostic evidence, not a Skill result or proof of repair.

An initial evaluator preparation command looked for the artifact in the wrong directory and exited before constructing input or starting a model. The empty `run/` directory is retained as preflight history; the actual diagnostic is `run-1/`.
