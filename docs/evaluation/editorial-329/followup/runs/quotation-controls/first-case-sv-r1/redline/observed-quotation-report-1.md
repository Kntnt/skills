# Fokuserad läsning av citat

Hela texten och samtliga fyra angivna kontraktsfiler är lästa. Båda citaten har bedömts i sitt sammanhang utifrån svenska, referenser och begriplighet.

Inga belagda redaktionella hinder i citaten. ”Den tiden” syftar begripligt på tiden för att enas om kategorierna. ”Nästa byggnad kommer i gång” fungerar som en begriplig förkortning för att försöket börjar i nästa byggnad; sammanhanget klargör innebörden. Det andra citatet uttrycker kundens egen nytta och förbehåll utan någon oklar referens eller störande idiomatik. Alternativa formuleringar skulle här vara preferenser, inte nödvändiga rättelser.

Ingen ändring föreslås. Källverifiering, mekanik och övrig redaktionell granskning ingår inte i denna läsning.
