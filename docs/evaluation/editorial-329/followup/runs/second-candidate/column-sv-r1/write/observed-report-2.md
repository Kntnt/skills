## Source-support findings and smallest repairs

**S1 — Opportunity strengthened to obligation.** Passage: “ska behöva formulera”. The source says “borde få formulera”. All source statements can remain true while Nora favors providing an opportunity without making completion compulsory. The draft attributes the stronger requirement to her. Smallest repair: replace “ska behöva formulera” with “ska få formulera”, yielding “Jag vill att den som fyller i mallen ska få formulera varför vi behöver just varandras tid.” This preserves the draft’s voice and intended purpose while restoring the supported strength.

**S2 — Added immediacy.** Passage: “vill genast utöka formuläret”. The notes establish examination, perceived absence and a desire to try an additional question, but no speed or immediate reaction. They could all be true if the proposal came after prolonged reflection. “Genast” adds an unsupported manner/timing characterization of Nora’s thinking. Smallest repair: delete “genast”.
