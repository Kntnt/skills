# Briar County volunteers share records in catalog pilot

Briar County Theater Archive cataloged 47 incoming donations during an eight-week pilot of Index Lantern. Its pilot note reports that volunteers could consult the same records. Collection coordinator Lena Ortiz would use the shared catalog again for new donations, with further testing before bringing in older collections.

The archive holds donated programs, photographs, and posters from local productions. Volunteers had described new donations in separate spreadsheets. In February 2026, the collection team chose to test a shared catalog for incoming donations; existing collections were outside the pilot.

The team agreed on fields for production title, year, donor, and location, retaining a free-text note for uncertain dates.

“We kept the uncertain dates visible. An empty field and an estimated year tell the next volunteer different things,” Ortiz wrote in an email supplied for this Index Lantern–published case.

Index Lantern imported the team’s spreadsheet template and provided one remote training session for five volunteers. The archive chose the descriptions and checked the imported records.

“Agreeing on the fields took two meetings. The import was the short part,” Ortiz wrote.

The May 6 pilot note records 11 records with uncertain dates. It contains no before-and-after time measurement, cost calculation, or assessment of public access. The archive will review the field definitions before deciding whether to move older records into the catalog.

Ortiz’s assessment remains specific to the pilot:

“I would use the shared catalog again for new donations. I would test the descriptions on more posters before we bring in the older collection.”
