## Material

Briar County Theater Archive holds donated programs, photographs, and posters from local productions. Volunteers had described new donations in separate spreadsheets. In February 2026 the archive's collection team chose to test a shared catalog for incoming donations, using Index Lantern. Existing collections were outside the pilot.

The team agreed on fields for production title, year, donor, and location. It retained a free-text note for uncertain dates. Index Lantern imported the team's spreadsheet template and provided one remote training session for five volunteers. The archive decided which descriptions to use and checked the imported records.

The archive's pilot note, dated May 6, records 47 incoming donations cataloged during the eight-week pilot. Eleven records retained uncertain dates. The note reports that volunteers could consult the same records, but contains no before-and-after time measurement, cost calculation, or assessment of public access. The archive will review the field definitions before deciding whether to move older records into the catalog.

Collection coordinator Lena Ortiz sent the following complete quotations in an email headed “Catalog pilot: notes for publication”:

- “We kept the uncertain dates visible. An empty field and an estimated year tell the next volunteer different things.”
- “Agreeing on the fields took two meetings. The import was the short part.”
- “I would use the shared catalog again for new donations. I would test the descriptions on more posters before we bring in the older collection.”
