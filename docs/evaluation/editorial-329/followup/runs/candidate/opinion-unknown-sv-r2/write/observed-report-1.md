# Källjämförelse

Jämförelsen av samtliga faktiska och tillskrivna påståenden i hela utkastet är slutförd. En iakttagelse:

## Tidsangivelsen kan ändra avsändarens krav

**Utkast:** ”Hamnbolagets styrelse bör vänta med beslutet om sex fasta eluttag vid Norra kajen till sommaren 2027.”

**Källa:** ”Det kommunala hamnbolaget föreslår sex fasta eluttag vid Norra kajen till sommaren 2027.” Vidare: ”Hon vill att styrelsen beställer jämförelsen vid nästa möte och återkommer till investeringsbeslutet när den är klar.”

**Problem:** I utkastets formulering kan ”till sommaren 2027” läsas som tidpunkten till vilken styrelsen ska vänta med beslutet. Källan knyter sommaren 2027 till bolagets föreslagna uttag. Kajliv vill vänta tills jämförelsen är klar; materialet anger inte sommaren 2027 som önskad beslutstidpunkt.

**Minsta reparation:** Stryk ”till sommaren 2027” ur första meningen: ”Hamnbolagets styrelse bör vänta med beslutet om sex fasta eluttag vid Norra kajen.” Om tidsuppgiften ska behållas, knyt den uttryckligen till förslaget: ”Hamnbolagets styrelse bör vänta med beslutet om de sex fasta eluttag som bolaget föreslår ska finnas vid Norra kajen till sommaren 2027.”

Inga ytterligare källstödsproblem har identifierats.
