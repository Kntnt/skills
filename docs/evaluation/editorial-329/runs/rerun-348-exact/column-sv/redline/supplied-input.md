# Ännu en ruta för det vi inte vet

Av Nora Vik, bibliotekarie

Jag granskar bibliotekets mötesmall. Där finns rutor för starttid, sluttid, deltagare och dagordning. Men ingen ruta för det beslut vi ska kunna fatta när vi går därifrån. Mallen ger plats åt klockslagen och namnen. Vad vi ska kunna göra med varandras hjälp får den som fyller i den själv komma ihåg att formulera.

Det retar mig att tid i kalendern så lätt kan behandlas som ett resultat i sig. Som om en början och ett slut tillsammans vore ett svar på varför vi behöver träffas. Det är min reflektion, ingen kartläggning av andras mötesvanor. En upptagen timme berättar när vi är upptagna. Jag vill också veta vad vi behöver den till.

Ändå tvekar jag inför min egen saknade beslutsruta. Jag uppskattar möten där kolleger upptäcker att de har förstått en fråga olika. Att få syn på skillnaden kan vara viktigare än att snabbt enas. Om mallen bara efterfrågar ett beslut, var skriver vi då att vi behöver förstå vad vi faktiskt är oense om?

Ett samtal kan också skapa förtroende. Eller hjälpa oss att upptäcka en fråga som vi inte visste att vi behövde ställa. Jag vill inte pressa sådana samtal mot ett beslut för att få något prydligt att fylla i. Det vore en märklig omsorg om vår gemensamma tid, om det vi upptäcker tillsammans inte fick räknas.

Kanske är det alltså en annan formulering jag söker. Den som planerar ett möte borde få skriva varför vi behöver just varandras tid. Också när svaret är att vi behöver undersöka något tillsammans och ännu inte vet vart undersökningen leder. Ett syfte behöver inte vara ett löfte om ett färdigt svar.

Mitt förslag är därför en fråga bredvid tiden: vad behöver vi förstå tillsammans?

Här finns förstås en viss komik. Jag granskar ett formulär och hoppas på ett bättre samtal genom att utöka formuläret. Ännu en ruta. Jag vet inte om den gör möten bättre. Men jag vill prova frågan, med tvivlet kvar. Starttiden och sluttiden kan få stå där de står. Däremellan vill jag ge plats åt något vi ännu inte vet.
