Granskad som debattartikel på svenska, utan särskild teknik. Alla sex fynd är åtgärdade. Den avslutande korrekturläsningen fann inga mekaniska språkfel.

Korrigeringsrundan tog bort följande påståenden eftersom de saknade stöd eller drog slutsatser som textens underlag inte medgav:

- Att kommunledningen hatar människor.
- Att alla vet att politikerna vill stänga ute äldre för att spara miljoner.
- Att bokningarna bevisar att 20 procent av kommunens invånare inte kan använda internet.
- Att avsaknaden av tidsmätning innebär att telefonbokningen inte kostar något.
