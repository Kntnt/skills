Each fresh installation supplied only its staged input; Redline never received the source package. All twelve parent sessions and their correction sessions expose the same model/effort, all twelve temporary roots were removed after evidence capture. [Verification](../runs/baseline/verification.json) checks the observed identities, revisions and cleanup.

The separate [Write record](../../records/write-gpt-2026-09-19-338-baseline.md) and [Redline record](../../records/redline-gpt-2026-09-19-338-baseline.md) were judged before candidate outputs were consulted. Write produced six complete drafts. The initial assessment missed an unsupported factual strengthening in opinion-sv: no claimed costing/funding became categorical absence of both (#349). A transparent source-aware F1 reassessment now rejects that draft; the original pass is retained in the record as superseded evaluator history. Case-study-sv separately has the specific qualitative L1 translation defect #341. Redline completed only case-study-sv, preserving its text but missing that idiom flaw. Five other Redline invocations fail at the mandatory closing Proofread YAML handoff (#339), so final-text criteria are explicitly skipped rather than assumed passed or worse than candidate. The two runs with real corrections also leave 125 UV scratch entries each (#340).

For manual reading, each case directory contains draft.md and Write's separate delivery-account.md. Only a truly completed result receives final.md (case-study-sv); failed cases have review-outcome.md and the original response. Intermediate corrections in article-en_GB and web-copy-sv are labelled as such. Every run preserves invocation, staged input, full response, native rollouts including corrections, before/after inventories, classified side effects and cleanup. The web-copy correction's reported inability to invent a missing ABT complication is retained as evidence of the baseline default, not silently repaired.

These six samples establish observed baseline behaviour only, not a general success rate or literary ranking. Failed invocations remain part of the comparison, and a successful candidate must still pass its own predeclared criteria.

## Reassessment affecting comparison

The opinion-sv baseline already changes “gör inget anspråk på att ha finansierat eller kostnadsberäknat” into “har varken kostnadsberäknat eller finansierat”. This is not merely economical wording: the latter asserts a fact the source does not establish. F1 therefore fails under the original frozen criterion, and a candidate exhibiting the same defect cannot be called a new regression on that dimension. This corrects the initial baseline assessment transparently; no output, source or criterion was altered.
