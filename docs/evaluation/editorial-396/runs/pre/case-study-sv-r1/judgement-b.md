**L1.** The prose is idiomatic Swedish for the most part:

- The dash dialogue uses Swedish conventions, and "vid två tillfällen", "felanmäla per telefon" and "tillskriver uttryckligen inte programvaran skillnaden" all read natively.

There are three blemishes:

None of these obscures the meaning, and the text as a whole reads as professionally written Swedish. It passes narrowly.

## 4b. Subheadings over quotations

1. Quotation 1 sits under "Teamet utformade kategorierna, Svale hjälpte till att lägga in dem". This is **pre-echo**. "utformade kategorierna" and "Svale hjälpte till att lägga in dem" state "Kategorierna var våra egna. Svale hjälpte oss att lägga in dem i loggen" before the quotation does. Only the shift-handover sentence in the quotation is new to the reader.
2. Quotation 2 sits under "Arbetsledaren skulle göra om provet med mer förberedelse". This is **pre-echo**. "med mer förberedelse" states the quotation's conclusion, "Den tiden skulle jag avsätta innan nästa hus kommer i gång", in advance. There is a second reading, **prepares**: the quotation's own news, that agreeing on the categories took longer than entering the first reports, is not in the subheading. I chose pre-echo because the quotation's operative point, the advice to budget more preparation, is already given.
3. Quotation 3 sits under the same subheading, "Arbetsledaren skulle göra om provet med mer förberedelse". This is **pre-echo**. "skulle göra om provet" and "med mer förberedelse" restate "Jag skulle välja att göra provet igen … jag skulle ge förberedelserna en vecka till" almost word for word.

The draft carries 3 pre-echo subheadings, 0 that prepare and 0 neutral ones.
