## 2. F1: fail

- **Ending: "could start where Fenwick had to: by agreeing what each status means, and checking the names, before any backlog goes in."** This fails for two reasons.
  - *(i) Modality change.* The source says only that the team "had to agree what ready for work meant". Holding back the backlog was the manager's choice ("postponed adding the backlog until the team had reviewed its status definitions"). Allowing more time to check the names is Vale's hindsight ("I would allow another week"). "Had to" turns the choice and the hindsight into a necessity.
  - *(ii) Dropped caveat turned into its opposite.* The source says the material establishes "not ... a recommendation for every workshop". The draft keeps only the first half of that sentence ("reported experience rather than a measured improvement in repair speed"). It drops the recommendation caveat and then ends by advising any workshop "weighing a shared schedule of its own". The hedge "could" does not cure this: the ending is still a general recommendation that the source explicitly withholds.
- **Byline: "By Thomas Barregren".** This is an unsupported attribution. The brief says "No author name ... is supplied", and the material names the interviewer only as "Benchline's case writer". The draft fills an unknown with a name that is not in the material. Readers would take him to be Benchline's case writer, and the material does not show that. The reply discloses the byline, but the published text still asserts it.
- **Standfirst: "held back the backlog".** This drops the condition "until the team had reviewed its status definitions", so a conditional postponement reads as an open-ended hold. The body restores the condition, which makes this minor.
- **Standfirst: "After trialling a shared bench schedule, ... approved".** The date of the approval is not given. It could have come before the six weeks ended. This is minor, and a reasonable inference from "continued use", but it is still chronology the source does not state.
- **Lead: "having chosen Benchline after checking".** The perfect participle puts the choice before the start of the trial, and the source does not order these events. A trial of Benchline makes that order likely, so this is a small inference and not a clear error.
- **Terms checked in both directions:**
  - "tell those statuses apart" matches "distinguish these statuses".
  - "repairs awaiting parts" (headline) matches "instruments were waiting for parts".
  - "Fenwick says" attributes to the workshop's own trial summary, which is supported.
  - "held back" is close to "postponed" apart from the lost condition.
  - "spend longer checking" (heading) matches "allow another week to check". "Spend longer" is slightly wider than "allow another week" but covers it.
  - "Before the trial" matches "Previously".
- **What the draft keeps correctly:** there are no invented events, emotions, scene or spoken exchange. The unmeasured items (repair duration, revenue, customer satisfaction) are kept as unmeasured.

No quotation stands without a bridge.

## 4b. Subheadings over quotations

1. **First quotation.**
   - Subheading: "The workshop set the statuses, Benchline configured them"
   - Quotation: 'We had to agree what ready for work meant. A part being in the building did not always mean that it had reached the right bench.'
   - **Prepares.** "The workshop set the statuses" names the subject, which is setting the statuses. The quotation's point is that "ready for work" was ambiguous, because a part in the building was not always at the right bench, and the heading does not state that.
   - Alternative reading: pre-echo, because "set the statuses" restates "We had to agree what ready for work meant". I rejected this because that sentence is the setup and not the point. The heading's second half ("Benchline configured them") belongs to the paragraph after the quotation.

   - Quotation: 'I would use it again for new jobs,' Vale wrote. 'I would allow another week to check the status names before adding the backlog.'

   - Alternative reading: prepares, because the heading does not carry the first half ("use it again for new jobs"). I rejected this because the change is the point the section is built on, and the heading says it first.

**Counts:** pre-echo 1, prepares 1, neutral 0.
