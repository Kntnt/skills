## Source-support finding F1: the submission's knowledge is not the package's knowledge

**Draft passage**

> Our submission also makes no claim to have secured the building owner’s consent for rehearsal use; it does not establish whether that consent exists.

**Supplied passage**

> The association's submission makes no representation that it has secured the building owner's consent for rehearsal use. The supplied material does not state the consent's actual status.

**What changes:** The first draft clause is supported. The second makes a different absence claim about a different document. In ordinary reading, “it” resumes “Our submission”. The material does not say that the submission leaves actual consent status unestablished. It says the submission does not represent that the association has secured consent, and separately says the supplied material does not state the actual status. A claim about who secured consent is not equivalent to a claim about whether consent currently exists. The source package is complete as supplied material; that does not make its summary the complete text of the submission.

**Both directions tested**

| Direction | Concrete case | Compatibility and result |
| --- | --- | --- |
| Supplied statements hold; draft's second clause fails | The submission explicitly records that the building owner refused consent for rehearsal use. The supplied package summarises only its lack of any representation that the association secured consent and does not include the refusal or report the actual status. | Compatible with both supplied statements. An explicit refusal is not a representation that consent was secured. A summary can omit that refusal. The submission would establish that consent does not exist, while the supplied material would leave its status unstated. No supplied statement excludes this case. **The case stands and establishes F1.** |
| Draft's second clause holds; the package-status statement fails | The submission leaves consent unresolved, but a separate item in the source package explicitly states that the owner granted current consent. | This would distinguish the two document scopes in the reverse direction, but it is excluded here by: “The supplied material does not state the consent's actual status.” This candidate is set aside on that exact supplied statement. It does not remove the surviving first-direction counterexample. |
| Draft's second clause holds; the submission's no-securement-representation statement fails | The submission says the association secured consent earlier, but says that its present validity is unresolved. It therefore does not establish whether consent now exists. | Excluded here by: “The association's submission makes no representation that it has secured the building owner's consent for rehearsal use.” This reverse candidate is also set aside on an explicit supplied statement. |

The finding is about support and attribution, not about proving that the owner actually refused or granted consent. The surviving case is hypothetical, not an added fact about Bellwick.

**Smallest supported repair preserving the expressed uncertainty:** Replace only the final clause with “the supplied material does not state that consent’s actual status”. The resulting sentence is:

> Our submission also makes no claim to have secured the building owner’s consent for rehearsal use; the supplied material does not state that consent’s actual status.

This preserves the supported absence of a representation and locates the status uncertainty in the correct material. If retaining the submission-specific assertion is essential, further support would need to state explicitly that the submission itself leaves consent status unestablished, or supply its complete relevant contents so that that assertion can be checked. The current material does not do so.
