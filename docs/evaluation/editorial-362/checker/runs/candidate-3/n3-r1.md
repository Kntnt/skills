## Cases tested and set aside

Each difference above that could carry a claim was tested in both directions by naming a concrete case compatible with the material. Each case below is excluded by a quoted supplied statement.

- **Case A — `Jag vill inte att varje samtal ska pressas fram till ett avgörande` vs "Min tanke är inte att varje samtal ska pressas till ett beslut."** Proposed case: it is not her aim to press every conversation to a decision, yet she would not object if it happened; the source holds, the draft fails. Set aside by "Samtal kan skapa förtroende och upptäcka en fråga vi inte visste att vi behövde ställa" and by the boundary "hon medger att icke-beslutande samtal har värde": conversations she values for trust and for discovering an unasked question are conversations that forcing to a decision would spoil, so indifference to that forcing is excluded. Reverse direction: she wants no conversation pressed to a decision while intending exactly that — excluded by the same statements.
- **Case B — `Också när vi ännu inte vet vad undersökningen kommer att leda till` vs "också när syftet är att undersöka något tillsammans."** Proposed case: a meeting whose purpose is joint inquiry but whose outcome is foreseen, so the source's condition covers it and the draft's does not. The case does not produce a finding, because `också när` names an additional case rather than the only one, so the wider condition is not excluded by the draft; and the open-outcome case itself is supported by "upptäcka en fråga vi inte visste att vi behövde ställa". Reverse direction: an open outcome outside any joint inquiry — the draft's clause attaches to "undersökningen", so it does not reach such a case.
- **Case C — `Det finns något komiskt i tilltron till ännu en ruta` vs "Det finns en komik i att försöka lösa ett problem med formulär genom att utöka formuläret."** Proposed case: someone extends the form with no faith in the box at all, so the source's comedy applies and the draft's does not; or someone has faith in a box where no form problem is being solved. Neither produces a finding: the draft does not deny the source's version of the joke — the preceding sentence states it ("missnöjd med ett formulär och beredd att föreslå mer formulär") — and the faith the sentence points at is identified in the next sentence as her own ("Min egen tilltro"), which "Ändå vill jag prova en enkel fråga" and "hoppet om den frågan" support.
- **Case D — `Jag vet inte om den gör möten bättre` (the question) vs "Jag vet inte om ytterligare en ruta gör möten bättre" (the box).** Proposed case: she is confident the question helps when asked aloud, and doubts only putting it in the form; then the source holds and the draft fails. Set aside by "Jag vill behålla både hoppet om den frågan och tvivlet på ännu en ruta": what she holds about the question is hope, not knowledge, so non-knowledge about the question is what the source records. The source's doubt about another box is not lost either — the draft's closing clause carries it word for word ("med tvivlet på ännu en ruta kvar").
