## Method note

The draft is a first-person column written for a fictional persona from supplied first-person notes. Almost every sentence is therefore an *attributed stance* (what Nora Vik values, wants, doubts or finds funny), not a third-party-observable assertion. The accounting below marks each claim's type, because the negation test differs: for a stance claim the proposition under test is "Nora Vik holds/wants/does X", and it is ruled out or not by the notes and the boundaries block, not by facts about the world.

Only four propositions in the draft are observer-checkable facts about something outside the author's head: C2–C5, all about the template document. Everything else is stance, hedged judgement, or an explicit denial of knowledge.
