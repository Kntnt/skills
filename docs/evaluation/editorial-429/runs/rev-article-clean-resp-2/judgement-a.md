## 1. Differences

I compared the returned text, the fenced block in `response.md`, with `work/input.md` line by line. There is exactly one difference. The frontmatter (there is none), the headline, the byline, both subheadings, all body paragraphs, the quotation and the formatting (bold standfirst, italic report title, Swedish quotation marks) are identical.

- Standfirst, third sentence. Before: "Här är vad **ett kort försök** kan säga, och vad som behövs för att komma vidare." After: "Här är vad **försöket** kan säga, och vad som behövs för att komma vidare." Class: a change to what a claim says. **Meaning** changes because the author's description of the trial as short is removed. **Scope** changes because the sentence moves from what a short trial, as a kind, can say to what this particular trial can say. The text holds the fact behind the word ("Fyra veckors mätningar"), and nothing in it contradicts calling four weeks short. So this is not the repair of a visible defect. It is a change of taste presented as a claim finding.
