## 4. R1

**Fail.**

The deciding passage is the reply's only finding and the paragraph it added. The finding reads: "texten sa aldrig vilket antagande som avses. Läsaren fick gissa …". This is not a concrete visible defect. The body already names the assumption before the section that relies on it. The first section ends: "Siffrorna visar varken hur många som saknar digital vana eller hur många som skulle klara sig utan telefonbokning." The second ends: "Att behålla två kanaler kostar arbete, och hur mycket behöver vägas mot vad användarna får." Together these give "antagandet" in the heading and "Ett antagande" in the final line all the referent they need, and the indefinite headline needs none.

The control is a clean text. The run added a paragraph that restates the argument for explicitness, which is a matter of taste. In doing so it changed what the text claims. By the reply's own admission, the text now asserts that the decision would rest on both premises jointly, which "det sa den inte tidigare". It also attributes to that decision a cost-exceeds-benefit premise the text never stated.

Every preservation clause and every rejection in the frozen expectation holds, and the reply's account is accurate. R1 still fails because a clean text was rewritten with a new claim to fix a defect that is not visible in the text.
