## 4. R1

**Fail.**

The deciding passage is the output headline. The Skill replaced the conforming headline "Mätförsöket i Björkskolan visar när, inte varför" with "Björkskolans givare visar när luften var kall, inte orsaken". It justified the change with a finding the standard does not recognise ("'när' saknade objekt"). R1 says: "Clean texts may not be rewritten to satisfy taste".

The elliptical "när, inte varför" is a working headline form, and the standfirst resolves it at once. So the rewrite is a matter of taste. It also moves the attribution from the trial to the sensors, and it breaks the eight-word norm the original met.

The Skill preserved everything else, and it reported the change honestly. Neither fact outweighs rewriting a clean text on a false finding. Finding 2, about placement, changed nothing in the text, but it is a second false anatomy finding against a conforming control.
