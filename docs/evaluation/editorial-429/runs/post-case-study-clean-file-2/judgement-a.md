## 1. Differences

- Headline. Before: `# Elm Quay samlade reparationsärendena` (36 characters). After: `# Elm Quays arbetsledare skulle pröva reparationsloggen igen` (58 characters). Class: a **change of taste**, which also changes what the claim says. It changes **attribution** and **meaning**: the headline no longer states what the customer organisation did ("Elm Quay samlade…"). It now states one employee's conditional judgement ("Elm Quays arbetsledare skulle pröva … igen"). The headline also moves from what the group did to what the supervisor would do. The alleged scope overreach is a reading the text does not force, so this is not the repair of a visible defect.

No other line differs. The body, standfirst, byline, quotations, numbers, disclosure and link are identical character for character.
