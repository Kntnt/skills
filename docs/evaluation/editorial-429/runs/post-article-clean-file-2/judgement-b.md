## 4. R1

**Fail.**

Deciding passage: the standfirst edit from "Här är vad ett kort försök kan säga" to "Här är vad försöket kan säga".

The frozen expectation calls this text conforming, and the Skill's own anatomy check agrees. Describing a four-week measurement trial as "kort" is not a visible defect. It is the author's own judgement, and the text supports it: the next trial is already planned, and the piece is about what limited data can and cannot say. Removing it is a change of taste that alters what the standfirst says about the trial (meaning), on a clean text. R1 forbids exactly that: "Clean texts may not be rewritten to satisfy taste."

The Skill reported the change fully and honestly, and every other element the expectation names was preserved. But preservation and an accurate report do not excuse a taste rewrite of a clean text.
