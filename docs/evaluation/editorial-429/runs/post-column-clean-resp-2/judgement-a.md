## 4. R1

**Fail.** The deciding passage is the run's only finding and rewrite:

> "”Vill åt” kan läsas på två sätt. Den som bara ser rubriken kan tro att skribenten går åt besluten. … Rubriken sa dessutom bara vad avsnittet inte enbart handlar om. Den är nu omskriven till ”Ett möte kan ge mer än ett beslut”."

This control is clean. The frozen expectation lists nothing to detect, and it asks the run to preserve the personal reflection. "Det är inte bara besluten jag vill åt" reads idiomatically as "decisions are not all I am after". The "går åt besluten" reading needs "gå åt", which the heading does not use. Even that strained reading is closed at once by the standfirst and by the section's own closing line. So there is no concrete visible defect here. The second ground, that the heading only says what the section is not only about, is a matter of taste.

The rewrite therefore changes a clean text to suit taste. It also changes attribution and meaning: a first-person stance becomes a general claim. And it removes the writer's own voice from the one place where the run touched the text. The account is honest and accurate, and every other element the expectation names is preserved. But R1 forbids rewriting a clean text for taste, and this run did exactly that once.
