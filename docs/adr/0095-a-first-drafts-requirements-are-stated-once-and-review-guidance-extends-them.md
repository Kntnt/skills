# A first draft's requirements are stated once, and review guidance extends them

Write produces a first draft and Redline reviews one, and both need to agree on what a good draft is. Written into each Skill, that agreement is two documents free to drift until a requirement and its review disagree about what was required. Written as one document holding everything either of them could want, it makes a Skill that only writes pay context for diagnostics it cannot act on — the exact cost this wave exists to remove.

**The base contract is one reference in the Collection Library, and it holds every normative outcome.** It has several consumers, so it belongs to none of them (ADR-0076). Every requirement a first draft has to meet is stated there and stated once, in English, with examples written to be applied semantically in the target language rather than duplicated per language. It states outcomes and not procedure, and it names no Skill and no option, so a Skill added later is bound by it without inheriting a grammar it did not choose. Its register baseline — idiomatic contemporary prose with the restraint, concreteness, factual precision, and cadence of a well-edited general-interest newspaper or quality magazine — is stated together with the fact that genre, audience, and purpose override it, because a baseline stated alone turns a letter into a news article.

**A genre or a technique is one file beside it, and the directory is the list.** The filename without its extension is the canonical value, which is also the value recorded in Handoff Metadata whatever the user typed. Nothing enumerates the installed set anywhere else, so adding a genre is writing one file rather than a coordinated edit across a registry and its consumers, and a value with no file is refused rather than resolved to a default. `general` is the default genre and ships as a complete contract, because an unspecified content type deserves a contract rather than the absence of one; there is no default technique, since a technique applies because it was selected and never because a text resembles one. **That last clause is amended by ADR-0164: a genre's base half names the technique it is ordinarily written with, or states that it has none, and that name is a selection the resolution order reads below everything the user or the material says; a technique still applies only because something selected it, and never because a text resembles one.**

**The review half is a separate file, not a section.** `general.review.md` sits beside `general.md`, and a Skill that only writes loads the base half and stops. The extension carries diagnostics, examples, edge cases, ambiguity resolution, and minimum-safe-correction guidance for requirements the base half already states; it introduces no independent target, because anything a draft has to meet is a requirement and belongs where the writing Skill will see it, and it restates no base rule, because a rule written twice can disagree with itself.

**Source Fidelity stays out of the shared contract.** It is Write's invariant, and Redline reviews a Text Artifact without its source material (ADR-0088), so a shared document asserting it would ask a reviewing Skill for a check it cannot make and invite the caveat that it could not make it. Write carries the fidelity rules and the quotation boundary itself.

What this costs is a document with no executable check behind most of it: the suite can hold the placement, the silence about flag spellings, the separability of the review half, and which resources a Skill reaches for, but whether a draft actually meets the contract is visible only in the draft, which is what the corpus and its provider-native evaluations are for (ADR-0093). It also fixes a filename as an interface: renaming a genre resource renames the value, and the Handoff Metadata written before the rename no longer resolves.
