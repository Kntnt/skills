# Guidance a precedence has settled is suppressed rather than ineffective

An evaluation run of Redline asked for a review of a text whose frontmatter carried a complete `kntnt` map, with a genre flag on the invocation and the Contextual Instruction *Review it as a PAC piece in Swedish*. The flag settled the genre, the map settled the technique and the language, and the instruction was therefore left with nothing to settle. The run refused it, and quoted the rule it was obeying: guidance wholly ineffective against a higher-precedence source is refused rather than silently dropped. The reader got an explanation of the precedence instead of the review they had asked for, and nothing in the collection was disobeyed — the refusal is ADR-0078's, carried in the same words by every shipped help page, and the editorial Skills' own `## Resolution` sections prescribe the opposite outcome in the same breath, level 3 of their ladder sitting where it does precisely so that levels 1 and 2 can settle a parameter over it (issue #146).

**A value a documented precedence has resolved against is suppressed, and suppression is never a refusal ground.** It is the mechanism working. A ladder whose lower level is there to be overridden cannot make its own overriding an error, and a user who names a genre on the command line and a genre in an instruction has written a redundant invocation, not a broken one. So **this record narrows ADR-0078** in one word: its *ineffective* reaches guidance with **no addressable effect at all** — guidance touching nothing the addressed Skill's contract addresses — and stops short of guidance a documented precedence has already settled. Everything else that record decided is untouched: the split, the reserved separator, the validation order, the semantic boundaries, the syntax refusal, and the conflicting, irrelevant, materially ambiguous, and scope-widening categories of the context refusal all stand exactly as they were.

**The run continues, and the delivery names the suppression where saying so is useful.** That vent is ADR-0078's own — an existing report names a material choice the guidance changed when that choice belongs in the report — and it is the right home for this, because what the user needs is not a refusal but the knowledge that the Swedish they asked for is not what they are reading. A mandatory acknowledgement is still not created: a run whose report has no place for the fact says nothing about it.

**Per-parameter suppression is documented semantics, not partial application.** ADR-0078's *mixed guidance is not partially applied* was written against guidance that is part **invalid** — part conflicting, part scope-widening, part unaddressable — where applying the good half would leave a caller unable to say what ran. It was never a rule about a ladder resolving parameters one at a time, which is what those `## Resolution` sections have always described. An instruction naming a technique the invocation left open and a language the artifact's map already settled is an ordinary invocation with one parameter landing and one suppressed.

**The precedence order is not touched.** Not its levels, not their order, and not which sources sit at which level. What this record settles is the fate of a value the order has already settled against, which was the one thing the order never said.

## Considered options

**Rewriting the editorial precedence sections instead** would mean saying what level 3 is for, and there is no answer: a level whose only distinguishing property is that higher levels beat it, made an error condition when they do, is a level that can never be used beside a flag or a Handoff Metadata map. Every artifact carrying a complete map would refuse every instruction, which is the opposite of what Handoff Metadata was built to allow.

**Reading the two rules as already reconcilable, with the run at fault**, was the cheaper diagnosis and it does not survive the evidence. The refusal quoted the envelope rule's own reasoning rather than inventing one, and it reproduces: sixteen of eighteen fresh runs on the base text refused in the #141 verification's A/B arm, beside the recorded run in `docs/evaluation/records/redline-claude-2026-08-25.md`. A rule sixteen readings out of eighteen apply the same way is not a rule the seventeenth reading misapplied.

**A Redline-local carve-out** would have been the smallest diff and the worst outcome. The contradiction is between a collection-wide envelope rule and a pattern three editorial Skills share, so a fix in one Skill leaves the same two rules disagreeing everywhere else and adds a third rule that only one Skill knows.

## Consequences

Every shipped `## INVOCATION ENVELOPE` section carries the narrowed rule in the same words, and the coding standard's two envelope clauses say the same thing to an author before the suite does. Each editorial Skill states the outcome where it resolves its parameters — under `## Resolution` in Write, Redline, and Unslop, and in the resolving step in Proofread, which states its one-parameter ladder there rather than in a section of its own — so a reader of the ladder meets the answer beside the level that is there to be overridden.

The cost is a judgement moved onto the agent. *No addressable effect at all* is a narrower test than *ineffective* but not a mechanical one, and an instruction addressed to a parameter the Skill does not have still has to be told apart from one addressed to a parameter something else has settled. The failure this narrowing makes possible is the mirror of the one it fixes: guidance that genuinely reaches nothing, quietly suppressed under the name of a precedence that never governed it. Naming the suppression in the delivery is what keeps that visible, and it is the reason the vent is stated in this record rather than left to each report's discretion.
