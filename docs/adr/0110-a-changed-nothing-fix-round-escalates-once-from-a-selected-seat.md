# A changed-nothing fix round escalates once from a selected seat

Until ADR-0085 every subagent a run started inherited the orchestrating session's own seat, and the wave loop's bounds were written in that world. One of them reads a fix round that changed nothing as proof that the finding was never mechanical, and stops the night on it. The inference is sound exactly once: when no fix the fixer could make means no fix the strongest seat the run owns could make. Routing broke that identity without anybody noticing, because the wave fix is a building role like any other and is routed like one — so the session that produces the no-op may now be the cheapest configuration the frozen snapshot could justify, and the run reads its silence as the branch's verdict rather than as the fixer's. A saving of a fraction of one round would then have bought the loss of every remaining hour of the run.

**A fix round that changed nothing escalates once where its fixer ran on a selected configuration, and stops the run where its fixer held the main seat.** The escalated round is one further routed decision, named `wave-fix-<n>-escalated`, made from the same frozen snapshot, carrying the no-op round as a verified failure with the wave check as its checker, and the run dispatches the same findings to whatever comes back. A second changed-nothing round stops the run whatever seat its fixer held: the escalation is one round and not a ladder. The escalated fixer is a fresh subagent and never the checking one, so the separation the whole loop is built on is untouched — the finder is still never the fixer, and what licenses the fixer's commit ahead of a verdict is still that the check which demanded it reads the result. This record **amends ADR-0098** in the single sentence that restated the no-progress bound as unconditional; that record's constructive obligation, its single-round bound on a named failing command, and its declined-findings bind are all untouched, as is ADR-0072's arrangement of the loop itself.

**The bound is the engine's rather than the step's.** The route verb accepts the escalated name, refuses a second escalation for one wave, and refuses an escalation for a wave whose fix round the run never routed. A bound only prose carries is a bound the session that happened to be handed that prose keeps, which is the same reasoning ADR-0098 gave for stating each of its bounds in exactly one surface; here there is a seam that can ask the question, so it asks it.

**The request states the safety facts, and Orchestrate owns no selection rule beyond stating them.** The wave fix runs under the strongest net the run has: the check that demanded it re-runs the whole gate and re-reads the branch, the fix is a commit on a branch that check reads whole, and the findings that licensed the dispatch already state each edit and what decided it. Those are exactly the facts model-selector's contract prices a cheap start and a bounded escalation on — an external checker, reversible work, and a retry the caller already owns — and the request had been stating none of them, so a dispatch that is objectively checked was being decided as though it were not. No tier ladder appears anywhere in this Skill: the checker's finding format is the evidence, the request carries it, and the frozen decision belongs to the routing module, per ADR-0074's division of building from the verdict.

**The Harness's own capability is one fact, said once.** Where the freeze leaves no complete adapter that can express a safe point, every building role of the night inherits the main seat, and every later one will too — the snapshot is frozen for the run. The plan and the dry-run routing preflight now carry that as a `routing_capability` line, and the report renders it as a fact about the Harness rather than as each decision's inheritance reason. A developer who wants to know whether tonight can be routed at all reads one line before the run instead of decoding a dozen identical inheritances out of the account after it.

**The road not taken was escalating unconditionally**, on every changed-nothing round whatever seat its fixer held. It was rejected because a no-op on the main seat is the non-mechanical case wearing the mechanical one's clothes, which is precisely what the original bound was written to catch: spending another main-seat round on it buys no information, only the cost of the round and one more hour of a night that has already stopped being productive. The condition is what makes the escalation an answer to the defect routing introduced rather than a general weakening of the bound.

**What this costs.** A stopped run can now have spent two fix rounds on the same findings rather than one, and the developer reading the account has to be told which, so the manpage carries a longer sentence about a case most runs never reach. The escalation's honesty depends on the run knowing which seat a round's fixer held, which is a fact of the frozen routing account and not of the branch — a run whose routing is gone stops before it could ask, which is the behaviour ADR-0085 already gives it. And the no-progress bound now reads differently depending on a fact stated three surfaces away from it, which is the price of not having a second copy of the bound to keep in step.
