# A ticket that rewrites an invariant declares that it builds alone

The overnight run that closed #99–#103 and #113 stopped on a branch that contradicted itself, and no file conflict was behind it. One ticket in the wave rewrote a repository-wide invariant — how a valued flag attaches its value, a spelling every shipped file is under — while two siblings in the same wave added brand-new Skills, written in the form that ticket was outlawing. Each branch was correct alone; only the merge could show the contradiction, and by then the new instances existed. No blocking edge could have prevented it: an edge names a ticket, and the instances a concurrent sibling would add did not exist when the tickets were written. Both the invariant ticket and its own sibling saw the risk and wrote it in prose — *not to be built concurrently* — which bound the one sibling they could name and nothing else.

**So a ticket declares its own exclusivity in its body, on a line opening `Builds alone`, and the planner gives it a wave nothing else is in.** The line is read the way the `Blocked by` line already is — a heading or a sentence, marked up or not — so the declaration lives with the ticket's substance, needs no tracker feature, and survives a tracker that has no relation to hold it. A ticket carrying it is a **Solo Ticket**. It takes the first wave its blockers admit it in, exactly the wave it would have taken without the marker, and takes that wave by itself; its otherwise admissible siblings fall to the wave behind it. Nothing else about planning changes — ordering, ceilings, and blocking behave as they did — and the plan names every such ticket, so a run says that a ticket rides alone and that its own body is why.

**An author writes the line where the ticket's subject is a repository-wide invariant: a rule every shipped file is under, which the ticket rewrites or newly enforces.** That is the whole rule, and it is deliberately narrow. A ticket that touches many files is not one of these; a ticket that changes what *every* file must look like is, because the set it governs includes the files a concurrent sibling has not written yet. Serialising such a ticket costs one wave of parallelism — minutes in an unattended night — against a branch-level contradiction every time the class recurs, which is a trade this repository has now priced from the losing side.

**The road not taken was a tracker relation of the shape *exclusive over surface X*** — the ticket naming the surface it rewrites, the planner keeping two tickets over the same surface apart. It was rejected for two reasons. A surface taxonomy asks the author to enumerate what does not exist yet: the new instances a concurrent sibling will add are precisely what cannot be named in advance, which is the same wall the blocking edge hit. And a registry of surfaces is a hand-maintained list of exactly the kind this repository has just watched decay — a list nobody updates is a planner confidently reporting that two tickets are independent. The declaration asks the author for the one thing the author reliably knows: that this ticket's rule reaches everything.

**The residual case is an invariant ticket whose author did not recognise it as one, and it is already handled.** The wave check reads the merged branch for coherence and reports a contradiction whose correction the branch has already determined, which the fix loop applies at the cost of one round. That is the same repair the abandoned run needed and could not reach. The marker and the loop back each other: the marker keeps the common case off the merged branch, the loop catches what the marker missed, and neither has to be perfect for the pair to hold. This is why the marker is a declaration rather than something inferred from a ticket's text — an inference wrong in the safe direction serialises a wave for nothing, and wrong in the other direction is the night that was lost.

**What this costs.** A ticket can now slow a run by asserting something nobody checks: nothing verifies that a Solo Ticket's subject really is a repository-wide invariant, and an over-cautious author buys silence with the run's parallelism. Two Solo Tickets admissible at once serialise into consecutive waves, and their ordinary siblings wait behind both. And the marker is a line of prose in a body, so a ticket that means it and spells it differently is a ticket the planner reads as any other — which is exactly the failure the wave check is left standing to catch.
