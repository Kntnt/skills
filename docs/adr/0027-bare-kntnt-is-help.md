# Bare `/kntnt` is Help

`/kntnt` with no arguments prints Help, not Status. Someone who types the manager's name with nothing after it does not yet know what to type next, and Help is the answer to that; Status answers a question they have not asked. Status stays one word away, and Help names it in the first line of output.

The earlier binding cost a beginner the one gesture that should teach the interface, and it made Status the only subcommand reachable two ways — an asymmetry with nothing behind it. Every other subcommand is reached by its own name, and now Status is too.
