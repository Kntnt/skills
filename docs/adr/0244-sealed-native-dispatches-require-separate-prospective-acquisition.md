# Sealed native dispatches require separate prospective acquisition

Recorded on 2026-10-03 while building #499. This decision adds an evaluator
method, not a claim that a historical encrypted instruction has been recovered.

## The boundary the archive could not establish

The retained #488 packet has eighteen native reply checks with matching sealed
parent and child instructions. Ten separate draft snapshots establish what a
parent wrote elsewhere, not what the checker received. #489's first native run
has the same gap; #492's clear-library correction lacks the complete original
allegation. Reconstructing those states from the delivered reply would make the
thing being checked its own evidence.

A bounded neutral Codex0.160.0 probe kept lifecycle hooks and appended passive
tool observers. SubagentStart supplied child metadata; spawn PreToolUse and
PostToolUse supplied no request. The native records retained identical sealed
parent/child task blobs. The same producer's fresh top-level initial user item
did preserve its supplied stdin byte for byte. A later bounded fresh
GPT-6-Astra/high CLI launch established that supported boundary and the exact
whole-task verification seat, independently of collaboration slot availability.

## The choice

Use an explicitly disclosed prospective evaluator dispatch through fresh native
CLI stdin when an exact task state is required and opaque delegation cannot
supply it. Keep the full child brief unchanged, bind its authentic initial user
item, actual context and completed result, and retain the caller's complete
consumption. Both controlled arms share the same overlay. The helper is
unshipped; normal editorial Skills continue to use their own native delegation.

This costs the ability to call the acquired arm uninstrumented reproduction.
That cost is recorded rather than hidden: ordinary native terminal observations
and independently judged semantic evidence remain separate requirements, and a
product claim cannot be inferred from the helper alone. Historical missing
states stay missing and their earlier verdicts stay intact.

The alternatives were to treat an authored snapshot as actual checked input,
wait for an unestablished decryption API, or insert outcome-seeking instructions
into a tested brief. None establishes the demanded boundary. A declared fresh
native transport establishes fewer causal claims, but establishes its actual
input and result independently. That permanent separation is the reason this
choice earns a record: archived instrumented evidence must never later be
silently promoted into natural native reproduction.

The current process is in
[the acquisition guide](../evaluation/harness/README.md). No old plan or
conditional nonreproduction branch is rewritten by this decision.
