# One lens applied alone ships narrower than the contract it belongs to

The editorial review reads a text against the base contract, the selected genre, the optional technique, the language's own guidance, and the shared anti-slop catalogue. Sometimes an author wants only the last of those, on a text that is otherwise finished — the argument is settled, the structure is right, and what is wrong is that the prose sounds like a machine wrote it. Typing the whole editorial contract to get one pass of it is the wrong gesture: it loads five documents to apply one, and it invites corrections to four things nobody complained about.

**A single lens gets a Skill of its own, and that Skill is narrower than the review rather than parallel to it.** It selects no genre, no technique, and no editorial contract; it loads the shared catalogue and the resolved language's anti-slop scope and nothing else; and it neither replaces the review nor grows into one. Substantive correction still has one workflow, because this Skill cannot reach the contract the workflow applies — the narrowness is what keeps the two from becoming two public interfaces onto the same job. A Skill added this way extends the editorial set rather than being enumerated by it: the next lens that earns one is another file and no coordinated edit anywhere else.

**It reads no more than it may act on.** The split is worth having only where it is spent: a Skill holding the review scope it is contracted not to apply is a Skill one round away from applying it, and a correction made against guidance the review never used is a change nobody asked for. So the language's wider review guidance stays with the Skill that applies the whole contract, and the correction brief this one dispatches carries the resolved language and no other editorial parameter.

**One pass was asked for, and one pass is delivered.** The full review closes with a mechanical pass because it has just applied an entire editorial contract and mechanical errors must be removed last. A single-lens Skill has done nothing of the kind, so it proofreads nothing, declares no Dependency on a proofreading peer, and names the separate gesture on its own page instead. The alternative — closing every editorial Skill with a mechanical pass for symmetry — makes a user asking for one thing receive two, and makes a Skill Unsatisfied whenever the peer it never needed is absent.

**It is user-invoked.** *This text reads like AI* is a judgement about how prose sounds, and a model reaching for a rewrite on that judgement unasked is deciding something the author is entitled to decide. The pass is available the moment somebody types it and never before.

The cost is a second Skill applying rules the review also applies, and two loop contracts to keep in step where a reader might have expected one. The second is answered by reuse rather than restatement — the Correction Budget's semantics are the Collection's, not this Skill's — and the first is the price of the frugality: a pass that loads one catalogue is a pass somebody will actually run on a finished text.
