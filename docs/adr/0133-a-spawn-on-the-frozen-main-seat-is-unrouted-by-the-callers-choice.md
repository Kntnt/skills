# A spawn on the frozen main seat is unrouted by the caller's choice

The delegation directive said: before spawning, route the full execution brief, user overrides, and checker or failure signal through Model Selector. Read strictly, that is a route artifact for every spawn — a fresh-context subagent on the main seat's own model included, where nothing is being chosen. The SeaTwirl Fast Track production run found the strict reading unworkable and formed a precedent instead: spawns onto a foreign execution surface were routed with full artifacts, while verifier and distiller subagents on the main seat's model were treated as pre-routed and spawned without one. It held all night, and it lived in one session's memory; the next session would either rediscover it or pay the ceremony (issue #206).

**A spawn the caller runs on the frozen main seat, with no model, deliberation, or surface override, is not routed; a spawn onto any foreign surface, model, or deliberation override routes exactly as before.** The boundary is the caller's choice and not a routing outcome. The ticket framed the shortcut as Model Selector's answer being `inherit` by definition, and in Model Selector's own vocabulary it is not: an execution request carrying any override is selected exactly or refused, never inherited, and where an adapter can express selection controls an automatic request may select a cheaper point than the main seat (ADR-0083, ADR-0104). What is never routed by definition is verdict authority (ADR-0085), and the directive names it in the same breath. So the directive states the two paths and the seat between them in one sentence, no judgment call is left for spawn time, and a verifier spawned on the frozen main seat costs zero Model Selector invocations.

**An unrouted spawn produces no `observe` attempt.** An observation begins from the immutable route decision the attempt launched from, and `observe` refuses an attempt without a fingerprinted decision (ADR-0089). A spawn that legitimately skipped routing has none, and the directive says so rather than sending the caller back to `route` for a decision object, which would reintroduce the ceremony the shortcut removes. Where capture is enabled, capture records the spawn as the inheritance that actually happened, under the `interactive_session` stratum ADR-0090 already gave ordinary unrouted work, so nothing in Model Selector changes for this record. The road not taken was a minimal local inherit-decision stub — a fingerprint of the frozen seat, written without invoking Model Selector, for `observe` to consume. It was rejected as a second emitter of routing artifacts: ADR-0083 makes Model Selector the owner of exact frozen routing, ADR-0089 has one module build and validate every observation, and ADR-0104 rejected a second implementation of adapter reachability living in a caller as exactly the drift those records exist to prevent.

That capture premise is narrowed by ADR-0156: an unrouted spawn capture observes no longer becomes any stratum of this contract at all, `interactive_session` included — it becomes a Usage Record in the store ADR-0156 gives ordinary work, carrying no outcome and entering no evidence ledger.

**The shortcut is paired with one sentence of counterweight.** Making main-seat spawns ceremony-free while every cheaper seat still routes tilts each spawn decision toward the expensive main seat — not because it is the right seat but because it is the frictionless one. The SeaTwirl run showed the drift in embryo: distiller subagents ran on a cheaper model by precedent from an earlier session, with the reasoning recorded nowhere, and under this shortcut a session facing ceremony for the cheaper seat and none for the main seat would rationally pick wrong. So the directive says that cheap judgment-in-noise roles — distillation, summarization, evidence collection — still consider a routed cheaper seat rather than defaulting to the frictionless main seat. It names no exploration policy, because none exists yet and a directive asserts only what stays true (ADR-0067) — a sentence **narrowed by ADR-0151**, which gives routing a bounded exploration term while leaving the directive itself naming none. The shortcut removes ceremony for the default; it must not remove the question.

**Orchestrate keeps routing every execution role.** Its account of what decided what is the one thing a run cannot rebuild, and its claim verb refuses a ticket the frozen account holds no decision for (ADR-0085). The shortcut is a property of the delegation directive alone, where no persisted account has to be kept true. This record therefore narrows ADR-0132 on that side only: Delegation routes execution before spawning it whenever the spawn leaves the frozen main seat, and Orchestrate routes as before. That side is narrowed by ADR-0172: where the frozen account inherits for a reason that is the snapshot's own, Orchestrate restates the decision it already holds for later roles rather than invoking the Interface again, and still routes the first batch of every run and every later role of a run that selected anything through it.

**What this costs.** An unrouted spawn leaves no trace in the evidence unless capture is on, so a machine without capture measures nothing about the work that runs on the main seat. In the SeaTwirl run that cost nothing — no verifier was ever observed, there being no external judge for a verifier — but capture changes the calculus, which is why the gap is decided here rather than left to be rediscovered. The directive grows, and its test's word budget is raised once, from 130 to 300, as the ceiling for the whole doctrine, the additions issues #207, #208, #209, and #210 make included; the ceiling is not a target. And the counterweight is a sentence rather than a mechanism: nothing checks that a distiller was weighed against a cheaper seat, and a session that skips the question pays the drift the sentence names. In return, a session spawning onto the seat it already holds does what the last one did, from the record rather than from memory, and every foreign spawn is routed, followed, and observed exactly as before.
