# A Rung is the next model where deliberation is exhausted or carried

This record supersedes ADR-0104 in the escalation dimension alone: everything that record settled about a carried destination, its attestation, its fingerprint, and the cold start it fixed stands, and only its closing decision — that a carried control has no reachable adjacency, so no rung is emitted on such a seam — is outrun (issue #215).

The ladder `route` climbed had one rung. `next_escalation` moved one adjacent portable level on the same model; the model itself was chosen once at cold start and never moved again. At the top of a model's mapped scale nothing was emitted, and on a Harness that carries deliberation by inheritance nothing was ever emitted at all. Claude Code is that Harness: every subagent it spawns inherits the spawning session's own deliberation, so on the maintainer's own machine the escalation path was unreachable in principle and Haiku, Sonnet, and Opus never formed a ladder at all. A collection whose stated goal is learning the cheapest configuration that holds quality cannot reach it on a ladder with one rung.

**A Rung is two-dimensional.** Inside one exact mapping it is the next mapped portable value in `PORTABLE_LEVELS` order, an unmapped level skipped rather than refused — a model that maps `low` and `high` and nothing between them has a two-rung scale, not a broken one. Where that scale is exhausted, or the Harness carries the deliberation control and no adapter addresses it, the Rung is instead the next model up by `model_capability`, regardless of provider, entered at the lowest portable value of its own that survives the request's filters. The step is larger than one deliberation level and this record says so plainly: it crosses a price boundary a level change does not, which is exactly why the ordering below is total rather than approximate.

**The ordering is shipped data, never a fact the module looks up.** ADR-0104 declined the model dimension because the ordering was one nobody had verified. That is no longer true: the capability numbers and their provenance ship in the frozen snapshot as derived priors, and the module reads its ladder from the snapshot alone, exactly as ADR-0083 requires. What changed is not the module's appetite for facts but the facts it is given.

**A Rung is always a point the same request already reaches.** Escalation resolves over the candidate pool selection resolved over, so every hard filter, explicit lock, adapter reachability check, and both main-seat ceilings have applied before adjacency is read. A point excluded as unreachable, over the ceiling, or outside the workload's capabilities cannot return as a rung, and a model none of whose levels survive is passed over rather than entered at a level nothing can launch. The ceiling stays inclusive in both dimensions, and a carried target is checked on the model dimension alone because it launches at the seat's own control.

**One exact launch is always determined.** Each mapping at the target capability collapses to the single value the direction enters it at, and the survivors are ordered by known `cash` first — a known price ahead of an unknown one, then the lower price — and after that by model, channel, surface, serving mode, adapter, and scale position. Equal capability, several mappings of one model, and a snapshot that prices one model and not another therefore all resolve to one launchable point rather than to a set a cold builder would have to choose from. Equal-capability alternatives remain available to measured selection; only the escalation rung is fixed this way.

**A lock is not a rung.** A request that pins the deliberation gets no escalation in either dimension: the pinned value is the caller's own exact instruction, and the pool already excludes every carried variant under such a lock. A request that pins the model needs no rule at all — an alias covering two models is already refused as ambiguous, so the pool holds one model and the ladder cannot leave it. Neither bound is a new guard; both fall out of filters the module already applies.

**Down is the same geometry, and no downward policy ships here.** The module's one internal `_adjacent_rung` helper takes a direction: descending, it steps to the previous mapped value inside a mapping and otherwise to the nearest lower model entered at the highest value that model maps, with the cash tiebreak unmirrored — cheaper still wins, because cost does not invert when capability does. Only the upward direction is wired to a decision. The downward one is exposed for the exploration ticket that will price it, so that when exploration arrives it inherits one geometry rather than writing a second.

**Three roads were not taken.** Escalating past the next capability to the strongest model the seat allows was rejected: the whole argument for cheap-first routing is that each step is paid for by a verified failure, and a policy that jumps buys capability nobody has evidence it needed. Widening the pool so a carried variant could be escalated into under a deliberation lock was rejected as reintroducing exactly the point the lock excluded, which would make a lock mean one thing at selection and another at escalation. And ordering within-model adjacency by `control_capabilities` rather than by the portable scale was rejected because two levels may share a capability number: adjacency has to be a total relation on the scale the request speaks, and capability stays what it is — an authority comparison against the main seat, not the ladder's rail.

**What this costs.** An escalation now crosses a cost boundary the caller may not have priced: a step from a model's top level into a stronger model is a bigger purchase than the retries this contract was written around, and it is bounded only by the main seat and by there being one verified failure behind it. A snapshot whose capability numbers are wrong now routes a wrong ladder rather than merely a wrong start, and the numbers are derived priors rather than measurements. Where several models tie on capability, the run always climbs into the same representative, so the cheapest of the tied models accumulates evidence and its siblings stay unmeasured until measured selection reaches them. In return, the Harness the maintainer actually works in has a ladder with more than one rung, which is the precondition for every measurement this collection intends to take.
