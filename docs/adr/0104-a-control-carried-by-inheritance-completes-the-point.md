# A control carried by inheritance completes the point

The overnight run that closed #99–#103 and #113 routed twelve execution decisions and inherited every one of them, each with the same reason: no selection control was available. The module behaved exactly as designed. `_adapter_can_launch` admits a candidate only through a concrete adapter carrying a complete flag translation, and the Harness in play — Claude Code spawning through its Agent tool — selects a model family while exposing no deliberation control on a subagent at all. No honest adapter could exist, so every candidate was excluded as unreachable and the audit trail came back complete, honest, and inert. Model selection was unavailable in exactly the Harness the maintainer works in, and had been since routing shipped.

That framing hid a fact. On a Harness that applies the spawning session's own deliberation value to the subagent it starts, the control is not unknown: it is the frozen main seat's exact value, which the routing snapshot already carries and which every verdict already inherits. The point was complete all along. What was missing was a way to say so.

**So the adapter schema learns one destination that is not a flag.** A native control mapped to `{"carried_by": "inheritance"}` is carried by inheritance: the translation is complete, it emits no launch argument, and it is a different fact from a mapping that is simply absent — which the module already refuses, and goes on refusing. The distinction is the whole point. An absent mapping means nobody knows what the subagent will deliberate at; a carried one means somebody checked, and the answer is the seat's own value.

**Such a destination is valid only beside the declaring session's attestation, verified rather than assumed.** The adapter carries `inheritance_attestation` — a statement that this Harness applies that value to subagents by default, checked against what the Harness actually does before the adapter is declared. Without it the same mapping launches nothing, and the point stays unreachable as before. The attestation cannot be computed: no script knows which Harness invoked it, which is why this collection's Harness Capabilities are answered by the running agent rather than tested, and why ADR-0083 already leaves the adapter as declared data rather than something the module derives. What the schema can do is refuse to accept the claim implicitly, and that is what it now does.

**A carried control is not a dimension route selects over.** It resolves to the frozen main seat's exact portable and native value, so the point yields that one variant rather than one per mapped level; only the model dimension of the authority ceiling can exclude it, a subagent inheriting the seat's deliberation being by definition at the seat's deliberation; and the configuration fingerprint carries the effective seat value, so recorded evidence binds and accrues to the configuration inheritance actually launches rather than to a level nothing ran at. An explicit deliberation lock is refused, never quietly satisfied — the variant is excluded as `carried_control_not_selectable` and the request refuses with `unavailable_override`, which is the field-lock rule the module already had. And bounded escalation moves only along a dimension the adapter can address: a carried control has no reachable adjacency, route defines adjacency on the portable scale alone, so on such a seam no escalation is emitted at all rather than a rung being invented in the model dimension out of an ordering nobody has verified. This extends the vocabulary of ADR-0083 without disturbing it: every launch-relevant field still has one explicit destination, and one of the destinations is now inheritance.

**The cold-start promise is settled in the same change, because this is where it first bites.** The contract promises that reversible, objectively checked work begins at the weakest plausibly sufficient configuration and escalates only after verified failure. The code took that branch under a different guard — the frozen `override_policy.cold_start` value, with an empty ledger — so a caller that declined unmeasured starts got inheritance for work whose failure its own checker catches, and the two surfaces disagreed about when a heuristic start happens. The code now learns the promise under exactly its stated guards: reversible work with an external checker or a declared failure signal takes the heuristic whatever the policy says, and `override_policy.cold_start` keeps deciding for everything else. It is stated in the routing contract for the first time, so the surfaces agree in both directions.

**Four roads were not taken.** A genuine partial-selection concept — a point selected in one dimension and unknown in the other — was rejected because an unknown control cannot be fingerprinted, and evidence that cannot bind to a configuration is not evidence about anything; the ledger would fill with records of runs nobody could reproduce. Mapping an existing portable value onto the seam's observed behaviour was rejected as a calibration claim nobody has verified: saying that this Harness's inherited thinking is `high` asserts a correspondence no measurement supports, and the module refuses to interpolate or guess a mapping everywhere else. Moving selection out of this module and into the orchestrating Skill was rejected against the records that put it here: ADR-0083 makes model-selector the owner of exact, frozen routing and ADR-0085 has Orchestrate reproduce none of its rules, and a second implementation of adapter reachability living in a caller is the drift both records exist to prevent. And the Harness's other seam was named rather than built: pre-declared agent-type definitions do expose a per-agent effort control, behind a user-gated tool, and the honest road there is an adapter over those definitions — a real adapter with a real flag translation, addressable rather than carried. It is a larger piece of work with a consent step in the middle of it, and nothing here forecloses it.

**What this costs.** The attestation is a claim the module cannot check: a session that declares it without looking gets exact-looking decisions resting on a Harness fact nobody verified, and the fingerprint will bind evidence to a configuration that never ran. That is a real hole, and the only thing holding it is that the declaring session is the one place with standing to answer. Selection on such a seam is also one-dimensional in practice — the model moves, the deliberation does not — so the frontier a run explores is narrower than the vocabulary suggests, and a failure has no cheap next rung to buy. And reversible checked work can no longer be held back from an unmeasured start by policy, which is deliberate: the checker is what makes the start safe, and a caller that wants no start has the choice of not calling.
