# Delegation files machine-judged evidence in one Cohort

ADR-0089 made external judgement a precondition for routed-work evidence and left every import to the user; ADR-0137 excepted Orchestrate's own verdicts and said in as many words that delegation kept the old rule. What that left is one routed path that teaches the next night and one that does not. A delegation session routed a subagent, had its work judged by something outside it, wrote the artifact the contract asks for, and named a scratch path in a report — and the evidence reached the ledger only where somebody remembered `/model-selector record` afterwards. A second gap made the first one worse than a missing convenience: the directive named no Cohort at all, and ADR-0145 keeps a row naming none out of every frontier, so the rows that were imported by hand were comparable within nothing when they got there. This decision supersedes ADR-0089 for delegation's machine-judged attempts, narrows ADR-0132 where it concludes that delegation cannot import, and narrows ADR-0137 where it reserves that conclusion to Orchestrate. The public `record` command remains the user's.

**A delegated execution request names one Cohort, and the attempt carries it.** Every request delegation routes states `stage` `delegated-execution`, `workload_cohort` `delegation/delegated_execution`, and no tags, and the observation copies all three from the request it answered. One Cohort is the whole taxonomy on this path rather than a stratum per role, because the frontier identity already holds the benchmark key beside the Cohort: a brief names its own key per workload, so distillation and code execution stay apart without splitting one Cohort into a frontier per brief. A Cohort that discriminates nothing is worse than none — it would put unlike work in one comparison — and a Cohort per brief is a frontier of one row, which measures nothing either.

**One eligibility rule, held once, read by both routed callers.** What a caller may file without asking anybody — an outcome established by an independent verifier, an objective checker, or a declared failure signal, plus the `abstain` and `infra_error` conditions no model produced — is `machine_judged()` in the Collection Library, beside the `record()` it gates. Orchestrate reads it there instead of the constant it used to keep, which is the same set the Standing Policy ratchet has always read: a machine that escalates a Cohort unasked and a machine that files a row unasked are answering one question, and two copies of the answer are how two seams writing one ledger come to disagree about what may enter it.

**The import is asked for by name.** `observe --import` writes the caller's artifact exactly as before and then files what it may; `--data` selects the ledger and is valid only alongside it. Without the flag the verb is what it was, so the `observe` a person runs by hand acquires no ledger side effect from a decision made for a directive. A refusal — a conflicting identity, an invalid row, a ledger that cannot be written — is reported per identity and stops nothing: the work the row describes is already done, and evidence is not a reason to fail it.

**What this costs.** Ordinary delegated work now writes the user's evidence ledger without being asked, and an import that brings a Cohort to its threshold can ratchet its starting Rung, so a night of delegation can change what the next route selects. The standing instruction grew by roughly fifty words against a budget that was exactly full, and the budget was raised rather than the doctrine trimmed. In return the two routed paths behave alike: the evidence a judged attempt produced reaches the next decision by itself, and the only thing a person still owns is the artifact nobody but a person could have judged.
