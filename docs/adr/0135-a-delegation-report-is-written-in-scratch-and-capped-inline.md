# A delegation report is written in scratch and capped inline

The delegation directive asked for a bounded, task-shaped report without defining the boundary, leaving each brief to rediscover the contract.

**Every delegation brief names a report file path inside the spawn's own scratch, and the subagent writes complete findings there; the brief caps the inline reply to a stated budget of conclusions only, with no raw command output or file dumps; the main seat reads the file only when its decision needs the detail.** The directive states the shape while each brief chooses the number; no default cap belongs in the doctrine. The main seat still verifies results independently.

The file belongs in the spawn's private scratch so concurrent delegations cannot collide or expose one another's reports. Keeping the full findings on disk preserves detail without making the inline handoff an unbounded context cost.

The cost is that a main seat must choose to open the report when detail matters, and a poor brief can still set an unhelpful cap. Those are brief-level decisions, deliberately outside the directive's fixed contract.
