# A fully determined fix is mechanical, whatever the gate says

An overnight run closed #99–#103 and #113 and then abandoned nine tickets on the boundary this record moves. Two of the tickets it had merged added new Skills, and both forked before the sibling that settled how a valued flag attaches its value landed, so their dependency-gate lines shipped in the spelling that sibling's own suite check forbids. Each ticket passed its verification honestly — the contradiction stood on neither branch alone — and only the merged branch could show it, which is the construction ADR-0072 exists for. The correction was two lines whose exact text ADR-0096 had already determined. The wave check saw all of this clearly: its own verdict called the fix mechanical, and it stopped the run anyway, because the mechanical verdict was admitted only where every gate command had passed. A defect that is mechanical and gate-failing at once had no verdict to fall into. The two axes are orthogonal, and the run is the proof.

**So the wave check's verdicts branch on the one question the run acts on — does fixing this require somebody to decide something — and a green gate is no longer a condition of the mechanical verdict.** Mechanical means what it meant: every finding's fix restates what the branch has already decided. What changes is that the finding may have come from a failing gate command as readily as from the reading, and that a stop is a finding requiring a choice between two tickets' intents or a gate failure whose correction is not so determined. This record **supersedes ADR-0072** in the half that stops the run on a failed gate exactly as on a disagreement; everything else that record settled — that the check reads the branch for coherence, that the finder is never the fixer, that the fixes loop to a fixed point — stands untouched.

**A failing command is reported mechanical only under a constructive obligation.** The finding names the failing command and states the exact correction — the file, the symbol or surface, the text as it stands, and the text as it must stand — and names the decided thing the correction restates: a record, the project's standard, a sibling ticket's landed work. Written that way, a session that has not read what the checker read applies it without deciding anything, which is the whole of what mechanical has ever meant here. A gate failure whose correction the checker cannot write down in that form is not mechanical, whatever it looks like: what cannot be written down is precisely what somebody else would have to decide. The obligation is constructive rather than a judgement about the failure's character, because a judgement is what the abandoned run already made correctly and could not act on.

**The mechanical claim is a claim of full determination, so a finding that names a failing command buys exactly one fix round.** Still red when the check reads the branch again — even after a round that changed things — is the stop: a determined fix that did not determine the outcome has been falsified by the branch itself, and a second round would be the checker guessing where it had claimed to know. A different command failing in a later round is a new finding with its own single round, the bound being on the claim rather than on the wave. The loop's existing bounds stand unchanged beside it: it ends when a round finds nothing, and a round that changes nothing stops the run. That last bound is amended by ADR-0110, which gives a changed-nothing round whose fixer ran on a selected configuration one escalated round before the stop.

**Findings an earlier round of the same wave's check declined bind the next one.** In the abandoned run's first wave, three check rounds read the same forward reference; two declined to report it, on grounds the branch's own records state, and the third had it deleted with no new fact, winning by speaking last. So from the second round on, the re-check's brief carries what earlier rounds explicitly considered and declined, each with the ground that round stated, and a declined finding is re-raised only on grounds the earlier reading did not have — the branch changed under it, or a fact it never had — named in the verdict. The dismissals bind because they came from peer checkers reading the same branch with the same evidence; this is not a session grading its own work, which is the arrangement the whole loop is built to avoid.

**The fixer's brief changes to match, and states the third separation in words.** The fixer fixes a gate failure exactly where the findings carry its determined edit, and only that edit — a repair of its own devising is a decision wearing a fix's clothes — and a failing command no finding names stays untouched, as every defect of the fixer's own discovery already does. It may re-run the one named failing command after fixing it and report the result; report only, because the wave check's own re-run is what decides. A coder now touches a failed gate, which nothing else in the run does, so the separation either side of it is stated rather than left to be inferred: the coder is never the finder or tester.

**Each bound is stated in exactly one surface and referenced from the others.** The constructive obligation, the single-round bound, and the declined-findings bind are the wave check's brief to state, because that brief defines what the verdicts mean; the run's step applies them and the manpage describes them, neither restating the rule. There is no second copy to drift, which matters more here than elsewhere: the run acts on the copy the subagent happened to be handed, and a bound stated twice is two bounds the moment one of them is edited.

**The road not taken was a fourth verdict shape** for the gate-failing mechanical case — a verdict of its own, beside the clean pass, the mechanical findings, and the stop. It was rejected because the run would act on it identically to the mechanical verdict, dispatching the same fixer and rerunning the same check, so the shape would buy nothing but a name; and because a fourth shape is a fourth thing two briefs can state inconsistently, in a taxonomy whose failure mode this record was written to fix.

**What this costs.** The check can now put a gate failure onto the fixer's desk, which is the class of work the change-nothing rule was written to keep away from a session nobody verifies — the constructive obligation is what stands in for that rule, and it holds in prose or not at all. A checker that writes a correction down confidently and wrongly spends a fix round and stops the run one round later than the old boundary would have, which is the price of the nine tickets the old boundary abandoned. The brief grows a placeholder that only the run can fill, so a round dispatched without it silently loses the bind. And a wave check now has to keep two things apart that read alike — a command it cannot write the correction for, and one it merely has not written it for yet — with nothing but its own honesty to tell them apart.
