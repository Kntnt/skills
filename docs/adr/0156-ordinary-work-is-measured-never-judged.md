# Ordinary work is measured, never judged

ADR-0090 gave a finished ordinary session one way to become evidence: wait in bounded pending review until a human answered `save`, `failed`, or `ignore`. The premise was that a Harness's own lifecycle payload could eventually carry a checker or a declared failure signal the way a routed attempt's completion does. It never has: Claude Code's session events carry a session identity, a transcript path, a working directory, and the event's own name, and nothing that could establish an outcome. Every captured session therefore took the one branch nobody built a way out of — addressed by an opaque identity nobody could connect to a session they remembered, returned as JSON from a hook the Harness never displays, and evicted by age, count, or size exactly as often as it was ever answered, which was never. The maintainer has settled the question the queue existed to ask: ordinary work is not judged at all. Quality comes from routed work, which something outside it already judges at a verdict (ADR-0137, ADR-0154); what ordinary work is worth is what it cost and how long it took on a given Seat, and that needs no verdict, no queue, and no question.

**A finished ordinary session produces a Usage Record, not a `RunObservation`.** It carries the opaque session identity, the Harness and its inventory revision, the exact Seat the work ran on, the usage categories the environment exposed — `MEASUREMENT_ALLOWED`'s seven keys, `tokens`, `tool_calls`, `retries`, `cost`, `quota`, `latency`, and `fallback_from` — and both instants and the elapsed seconds between them. It carries no outcome, no Outcome Authority, no checker, no condition, no Cohort, and no configuration fingerprint: a routed attempt's fingerprint exists because something judged the point it names, and nothing judges a Usage Record. Every measurement the environment did not expose stays an explicit `null`, exactly as it already does for a routed attempt.

**It is appended to its own append-only store, `usage-records.jsonl`, beside the evidence ledger.** A second store rather than a second kind of ledger row: `record` already refuses a row with no verdict, correctly, so a Usage Record was never expressible in it, and giving quality's own file a row nothing judges would be the thing every future reader of that file has to learn to skip. Idempotency is by session identity and Seat — `usage_key`, a digest of the two — so the same finished session appended twice is skipped, not repeated, the same discipline `record` already keeps for a run key.

**A session that ran on more than one Seat produces one Usage Record per Seat.** The dimension this whole feature exists to measure is model and deliberation, and a user who switches either mid-session ran two configurations, not one; each Seat's Usage Record is timed on that Seat's own first and last turn rather than on the whole session's start and end. How usage divides between two Seats that were both active is decision 5 of issue #225's own ticket to settle; this record settles only that the multiplicity is one row per Seat, and what each row is timed on. A `session.error` signal ends the session exactly as `SessionEnd` does: there is no outcome left for an error to carry, so it is not an infrastructure verdict any more, only the same ending every other one is.

**Nothing waits for a human, ever.** The pending store, the `review` verb and its three actions, the notification path and its debounce marker, the retention bounds, and the reconciliation of an abandoned draft into pending review all leave the Skill entire — there is no queue left for any of them to serve. A session that ends abruptly contributes whatever its own Usage Record establishes and nothing more; there is no draft promoted to pending, because pending does not exist to promote it to.

**A Usage Record is never quality.** It enters no derived frontier, contributes to no success rate, clears no quality floor, and produces no evidence record — the same rule ADR-0145 already states for a ledger row that names no Cohort, applied here to a record that names no outcome either, because both are one rule: work never grades itself, and a row nothing judged is not a verdict wearing quieter clothes.

This decision narrows ADR-0090 in exactly three places, and no others: the sentence declaring captured work "a seventh stratum rather than a second representation," narrowed because captured work is now a second representation on purpose; the paragraph sending unjudged work to bounded pending review, narrowed because nothing waits for a human any more; and the retention paragraph bounding that review at thirty days, a hundred drafts, and a mebibyte, narrowed because there is no waiting room left to bound. It also narrows ADR-0133, where it named the `interactive_session` stratum captured work no longer carries, and narrows ADR-0145, where it counted automatic capture among the reasons a Cohort-less row is optional — capture no longer writes a ledger row of any kind, Cohort-bearing or not.

**What this costs.** The collection now keeps a second small store instead of one, and a Usage Record on disk answers no question about whether the Seat it names did good work — a reader who wants that goes to the evidence ledger and finds nothing about ordinary work there, which is the point rather than a gap. The `--review`, `--action`, and the pending fields of `--status` a user may have grown to check are simply gone, and a session a Harness ended abruptly with no further signal at all leaves an orphaned draft on disk with no daemon left to sweep it. In return, every finished session writes down what it cost without anyone remembering to ask, the evidence ledger keeps meaning exactly what it always meant, and a queue nobody was ever going to answer stops existing rather than going on addressing itself to nobody.
