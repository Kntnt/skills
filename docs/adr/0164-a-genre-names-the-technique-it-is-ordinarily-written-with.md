# A genre names the technique it is ordinarily written with

A technique applied here only because something selected it, and the things that could select one were enumerated: the invocation, a recognized map in the material's frontmatter, or an instruction naming one. Below them the default was no technique at all. That arrangement exists so that no run reads an arc off the shape of the text in front of it, and it does that.

It also meant that most of what this Collection writes was written with no spine unless the person invoking knew to ask for one. The installed genres are not neutral about that. An article, a column, an opinion piece, a case study, a teaser, and a page of web copy are ordinarily written with a narrative arc, and a report with the analytical one — the pairing ADR-0163 had to scope was the default the arrangement this Collection replaced gave every report. A user who named a kind of text and no technique got a draft with no arc, and nothing anywhere told them one had been available: the techniques were installed, the practice was settled, and the two met only for somebody who already knew both.

**A genre's base half names the technique that genre is ordinarily written with, or states that it has none, and every genre in the directory states one or the other.** The directory is the list, so what makes that exhaustive is the directory at the time of writing and no list written anywhere else (ADR-0095). Nothing enumerates the mapping: the arrangement this Collection replaced kept it in a hand-maintained index beside the genres, which is the second statement of what is installed that this collection refuses everywhere and the reason adding a genre there was never one file. Here it stays one file, and a genre that says nothing about this is incomplete in the way a genre with no opening is incomplete.

**The name is a level of the resolution order: below the invocation, a recognized map and an instruction, and above no technique at all.** Every Skill with the parameter — Write and Redline — carries the level in its own ladder, reads it out of the genre that was settled and out of no other resource, and settles the genre first because the level depends on it. What the genre supplies is a selection and not evidence: an installed genre names its ordinary arc whatever text is in front of the run, so nothing about the material has been read to reach it. A genre naming none leaves the level below it standing, which is the default that was always there.

**Naming a technique is not inferring one, and this amends ADR-0095 in one clause of one sentence.** That record settled that a genre or a technique is one file beside the base contract, that the directory is the list, that a value with no file is refused rather than resolved to something near it, that `general` is the default genre and ships as a complete contract, and — the clause this record amends — that there is no default technique, since a technique applies because it was selected and never because a text resembles one. The half after the comma is what stands exactly as it was: nothing reads an arc off the material or off the draft, a text that falls into a shape has not selected one, and the licence a run has when it infers a genre reaches the installed openings and stops there (ADR-0115). What the amendment changes is where a selection may come from, never that a technique comes from a selection.

**The statement sits below the resource's requirements rather than in its opening.** A run settling an unnamed genre reads the `# <Name>` heading and the paragraph under it of each installed resource, and nothing further of any of them (ADR-0115). A technique named up there would enter that reading, and a run choosing between genres would then have an arc in front of it while deciding which kind of text this is — which is reading a technique off the material by a longer route. Below the requirements it is out of reach of inference and in reach of the run that has already settled the genre, which is the only run that needs it.

**The Handoff Metadata records a genre-supplied technique exactly as it records any other**, and `none` in a recognized map is read back as a value rather than as a gap. That reading was free before, because both readings ended at no technique; with a genre able to supply one it is the difference between a draft written without an arc being reviewed without one and being reviewed against an arc nobody chose. The map is worth writing precisely because a later run resolves what the earlier one resolved, so it settles the parameter where the map sits, above the genre's level, and is not a technique that failed to install.

The road not taken was a default technique for the Collection: one arc, applied wherever nothing named another. It would have given every text a spine at the cost of the only thing a genre knows that a collection-wide default cannot — that a report is not written as a story and a press release is not written as an arc at all. The other road was to leave the mapping in a registry, one file naming each genre and its technique, which is how the arrangement this Collection replaced did it. It reads better than nine statements until somebody adds a genre and does not update it, and then the collection has two answers to what is installed and no way to tell which is stale.

**What this costs** is a text under a genre that names an arc, wanted without one, needing a sentence to say so. The invocation's technique flag names installed resources, so it cannot name none; refusing the genre's arc is an instruction or a map that carries `none`, and that is a gesture a user has to know about. It also makes ADR-0163's scoping the ordinary case rather than an occasional one: a genre with a fixed order and a technique with a section-level arc now meet on most runs, so the line that keeps a report's answer at the top while its sections finish where their tests finish is exercised constantly and is held by prose. And whether a run read the statement at all is visible in a draft rather than in an assertion — the suite can hold that every genre states one, that both Skills carry the level and the delivery, and that nothing widened the inference licence, which is where this collection's checks have always stopped (ADR-0093).
