# References lines say `read when` the class of work

A pointer that lists example terms from the target (`CONTEXT.md` — Select, Harness, Collection) does not fire on the unlisted terms. The `agents-md` skill writes every References line as `- \`<path>\` — read when <situation>`, where the situation is the class of work that covers every reason to open the file. Completeness is the test: if any heading or term in the target would not fire the line, the situation is too narrow.
