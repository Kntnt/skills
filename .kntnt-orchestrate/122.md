### Changed

- `/orchestrate` now settles an integration collision confined to generated files by regenerating them instead of dispatching a repair. Both collisions in the run that closed #99–#103 and #113 included `skills/kntnt/catalog.json`, and every wave that merges two Skill-touching tickets would have collided there again, predictably and forever: the file is the output of a deterministic command over the tree, so two builders who each regenerated it honestly cannot produce the same bytes, and each such collision cost a routed repair subagent and a full re-verification to reproduce what one command already knows. Where every file a merge could not settle is one the repository declares generated, the run now runs those files' declared generators on the merged tree, commits the result as the merge itself, and dispatches no repair for it; the merge says on the branch what settled it, and the run's account names the ticket and the files rather than reporting a merge that never collided. What counts as generated is read off a declaration and never guessed: a repository names its generated outputs and the command producing each in `.kntnt-orchestrate/generated.json`, this repository declares the Catalog there with the line the contributing guide already gives, and a declaration that is absent or unreadable declares nothing, leaving that repository exactly the behaviour it had. A collision touching any file no declaration names takes the repair path unchanged, and so does the mixed case — a disagreement with a generated file beside it is still a disagreement — as does a collision whose generator failed, left anything unsettled, or wrote outside what it declares, where the merge is undone and the branch left as it was. What licenses the commit ahead of a verdict is the arrangement the wave's own note-applying commits already stand in: the check that follows reads the branch whole, so no regeneration escapes being read. ADR-0106 is the record; it narrows ADR-0055's reach over every collision, and names the run-owned README as the road not taken, several tickets naming a README section in their own acceptance criteria (issue #122).
