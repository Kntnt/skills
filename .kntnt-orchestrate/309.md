CHANGELOG.md
### Changed

- Model Selector's profile records the makers you want models from — Claude (`anthropic`), GPT (`openai`), Grok (`spacexai`) — in place of the list of model ids you enabled, and every model a chosen maker offers is eligible. The list meant a model the catalogue gained later stayed disabled until somebody added it by hand, so nothing new ever came into use by itself: seven ids stood on the maintainer's machine. `setup` now asks which makers to use beside the channels it already asks about, and its question on single models is gone; `setup_apply.py` writes `makers` and neither `providers` nor `models`, refuses a profile carrying either, refuses `makers: []` ("choose at least one maker") and a maker the catalogue holds no model of. A catalogue model is a candidate where its maker is chosen and the call reaches it exactly as before — a channel pays for it, or it belongs to the caller's own provider — and `--scope=all` is still the whole catalogue. No single model is chosen or left out within a maker, and a `--model` lock is answered as before. The generated `kntnt-*` agent definitions follow the chosen makers: every Anthropic model at every supported level wherever Anthropic is chosen, with no channel needed, and none for a valid profile that does not choose it. A missing profile, one in the old shape (a `models` list and no `makers`) and a damaged one — unreadable, carrying an invalid entry or an unknown maker, or `makers` beside a leftover list — now all stand in as a profile choosing no maker, so every call not locked to a model inherits the caller's own seat with a note naming `/model-selector setup`. The stand-in used to be the whole catalogue, a wider pool than anyone chose and not what ADR-0182 said. A sync without a valid profile, which `update` runs, leaves the definitions untouched and creates no directory, reporting `definitions: null` and `created_directory: false` with a note. A profile in the old shape is not translated: run `/model-selector setup` again after upgrading. `status` names each catalogue maker the profile does not choose as not chosen. `CONTEXT.md` defines Maker; `docs/rules/routing.md`, `SKILL.md`, `help.md`, `help/setup.md`, `help/status.md`, `help/reset.md`, `help/update.md`, `references/setup.md` and the README describe makers in place of a model list, and ADR-0190 records the decision (issue #309).
