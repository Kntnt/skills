`CHANGELOG.md`

### Changed

- Capture reads a subagent's own record when that subagent stops and the session's own record when the session ends, and it installs a hook at those two moments alone. Four moments were installed on Claude Code and three on Codex, and only the last of them ever did any work: a start and a turn were answered by writing a draft holding the session id, the harness and an inventory revision that the end payload already carries, so every turn of every session started a `uv run` that did nothing, and the eleven drafts sitting in the maintainer's `capture/drafts/` are eleven sessions whose work — every subagent among it — was never measured at all, the one read happening at an end those sessions never reached. Delegated work is what this collection measures most of, and Claude Code names the stopped subagent's own transcript in its `SubagentStop` payload — `agent_transcript_path`, established from Claude Code 2.1.263 as installed, beside the `transcript_path` every hook carries and which at that moment names the parent session. That one file is now read the moment it is finished, bounded exactly as the session's own read is bounded, and its unit written to `pending.jsonl` under the parent session's identity; the grading pass stays at the session's end, where one pass answers the whole session rather than one per delegation. A session's own end reads the session's own transcript and nothing under `subagents/`. Codex and OpenCode keep their finishing moments alone, no record either of them keeps being one this collection knows how to split.

### Removed

- The per-session draft, and the `capture/` directory it lived in. Every field a draft carried was rebuilt from the end payload before the draft was ever read, so the file was written for nobody and read for nothing it did not already have. `capture/` now joins the paths `reset --evidence` names as what an earlier design left: previewed beside those files and removed whole.
