`CHANGELOG.md` — one entry under `## [Unreleased]`, in `### Changed`:

- The Manager reads its own invocation through the engine. `skills/kntnt/SKILL.md` opens by running `kntnt.py invoke --here="$HERE"` with the payload on stdin, continues from the JSON on exit 0, and prints stdout verbatim and stops on any other exit. The help routing its body and `steps/help.md` carried, the verb list of `## Arguments`, and the prose that said what the script does with a flag a verb has no use for are gone — the engine reads all of it off the `argument-hint` and the shipped pages, which are unchanged. `## Arguments` keeps what the engine cannot know: what `--project`, `--yes` and `--dry-run` mean to the verbs, and that only `--yes` in the current Formal Invocation authorizes an unattended Global Update. The Steps read the verb from `path` and pass the flags on as they stand; the help step runs the script on the engine's operand and nothing else. The engine's dependency gate reads the Manager's own directory as declaring nothing, the Manager being no Catalog entry and carrying no marker for the sweep to read. Every help form prints the same page as before, held by the suite against what the script printed for it. Every documented refusal keeps its substance — the stray flag named on the first line, the addressed verb's SYNOPSIS verbatim, a route to that verb's page — and the suite holds each one against the script's own refusal of the same form; only the spelling is now the engine's, common to every Skill: `'/kntnt select' takes no '--force'` and `see '/kntnt select --help'` on stdout, where the script wrote `select takes no '--force'` and `see '/kntnt help select'` on stderr. Piloting the Manager found one price of the engine too high to pay: `help select --yes`, a refusal the Help page documents, reached the script as the operand `select --yes` because a last single operand slot took the rest of the line, flags and all. The engine now refuses a flag the Skill declares that is written after an operand, as out of order — which is what every page's DIAGNOSTICS already promised — while a dash-prefixed word the Skill declares no flag for stays text and a Skill declaring no flag at all still takes any such token as operand; `docs/rules/skills.md` states the rule, and `/commit fix the --yes bug` is refused as its own page says it is. `docs/rules/skills.md` also says what the `## Invocation` section of a body that calls the engine carries (ADR-0181).
