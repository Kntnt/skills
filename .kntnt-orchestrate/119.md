### Added

- `/model-selector route` can now select a model on a Harness that exposes no deliberation control on the subagent it spawns, which is the seam Claude Code's Agent tool presents and the reason every routed decision under it came back inherited. A frozen adapter may map a native control to the destination `{"carried_by": "inheritance"}`: the Harness applies the spawning session's own value to the subagent it starts, so the translation is complete and emits no launch argument — a different fact from a mapping that is simply absent, which still refuses. Such a destination is reachable only beside the adapter's `inheritance_attestation`, the declaring session's statement, verified against what the Harness actually does before the adapter is declared, that the Harness carries that value by default; the same mapping without it launches nothing. A carried control is not a dimension route selects over: it resolves to the frozen main seat's exact portable and native value, the point yields that one variant rather than one per mapped level, only the model dimension of the authority ceiling can exclude it, and the configuration fingerprint carries the effective seat value, so recorded evidence binds and accrues to the configuration inheritance actually launches. An explicit deliberation lock is excluded as `carried_control_not_selectable` and refused with `unavailable_override` rather than quietly satisfied, and bounded escalation moves only along a dimension the adapter can address — a carried control has no reachable adjacency, so no rung is emitted there at all. The same change settles the cold start the routing contract promises: reversible, objectively checked work — work with an external checker or a declared failure signal — now takes the heuristic start whatever the frozen `override_policy.cold_start` value says, that policy keeps deciding for every other unmeasured automatic request, and the Model Routing Module states both halves for the first time. ADR-0104 is the record; it also names the roads not taken, the Harness's other seam among them (issue #119).
