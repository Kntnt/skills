`CHANGELOG.md`

### Added

- The Collection Library now carries the delivery contract every Skill that produces a Text Artifact follows, so the rule is stated once before any of them consumes it. Delivery is non-mutating by default: the Output Target is the agent response, and a run that keeps it changes nothing on disk, whatever local file supplied the source material. An explicit path that does not exist creates exactly that one file, an explicit path naming an existing file overwrites that exact file without any additional force option — naming the path is the authorization — and an explicit directory derives a filename from the source basename, a referenced URL's title, or the Skill's own working title, keeps a suitable text extension, and never overwrites what it derives onto: it keeps one stable stem and takes the first free numbered candidate in ascending order beginning at `-2`, so `my-file.md`, `my-file-2.md`, and `my-file-3.md` grow one sequence instead of forking a new stem at every collision. Replacing a source has exactly one name: In-place Editing belongs to the Skills that review an existing text, requires exactly one writable local source file, excludes a simultaneous separate output option, and is refused for inline text, URLs, uploaded or read-only sources, and more than one Text Artifact; an output path equal to the input path is refused in favour of it, and a Skill that creates a text never edits the material its brief came from. A response-targeted or in-place run that changed nothing writes nothing and returns a short no-change status in the Text Artifact's own language, while an explicitly selected different file or directory still receives the complete text, because creating that artifact was the request. Every contradictory, meaningless, or unusable output request is refused before the first side effect and leaves no partial effect behind, under the Collection's ordinary diagnostic and help conventions. The reference states behaviour and no flag spelling, so each Skill keeps the grammar it exposes these rules through. ADR-0091 is the record this implements (issue #99).
