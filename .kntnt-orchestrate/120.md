### Changed

- `/orchestrate`'s wave-fix dispatch now states the safety facts that price it, and a fix round that changed nothing is read against the seat its fixer held instead of ending the run outright. The route request for a mechanical wave fix carries the wave check's own re-run as its declared external checker, states that the work is reversible — a fix is a commit on a branch that check reads whole — and states the retry the loop already owns, which are exactly the facts the routing contract prices a cheap selection and a bounded escalation on and which the request had been carrying none of. The Skill states them and stops there: no tier ladder of its own stands anywhere near the dispatch, and the frozen decision remains the routing module's. Because the fixer may now hold a configuration cheaper than the orchestrating seat, the old inference behind the no-progress stop — no fix the fixer could make means the finding was never mechanical — no longer follows on its own: where a changed-nothing round's fixer ran on a selected configuration, the run routes exactly one further decision, `wave-fix-<n>-escalated`, from the same frozen snapshot, carrying that round as a verified failure with the wave check as its checker, and dispatches the same findings once more to whatever comes back; where its fixer held the main seat, the run stops exactly as before, and a second changed-nothing round stops it whatever seat that round ran on. The escalated fixer is still a fresh subagent and never the checking one. The engine owns the bound rather than the paragraph describing it: it accepts the escalated name, refuses a second escalation for one wave, and refuses an escalation for a wave whose fix round was never routed. Where the frozen context leaves no complete adapter that can express a safe point, the plan and the dry-run routing preflight now carry one `routing_capability` line saying so, and the report renders it as a fact about the Harness rather than as a dozen identical inheritance reasons read out of the account afterwards. ADR-0110 is the record; it amends ADR-0098's restatement of the no-progress bound and names unconditional escalation as the road not taken (issue #120).
