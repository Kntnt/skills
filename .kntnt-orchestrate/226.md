### Changed

- Model Selector's `recommend`, `chart` and `compare` now report observed usage per named Seat alongside their quality and cost evidence. For the selected point and its frontier neighbors — the same points `recommend` already names, and no wider pool — a new section titled `Observerad förbrukning` states what each has actually cost in the Harness-counted token categories and how long it has actually taken, drawn from this machine's own Usage Record store, with the record count and the earliest/latest instant behind each figure; `chart` and `compare` carry the same figures as columns on their existing table. A figure no record supports is stated as absent, `null` on the tables, and none of it enters a frontier, clears a quality floor, breaks a tie, or feeds the frozen objective — the same profile and ledger, with and without Usage Records, select the same point. The status banner is unchanged; matching is by `(model, portable_deliberation)`, the coarsest identity a frontier neighbor and a Usage Record's own Seat both carry, so a delegated Seat whose portable deliberation issue #225 could not resolve is absent from every row's count rather than silently folded into the wrong one (ADR-0161).
