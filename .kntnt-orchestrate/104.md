# Entries this ticket owes files the run writes

## CHANGELOG.md

Under `## [Unreleased]`, in `### Added`:

- The Collection Library now installs the genres and techniques `/write` selects among: `article`, `report`, and `press-release` beside the `general` default, and the `abt` and `pac` techniques. Each genre states what its kind of text owes its reader on top of the base contract and nothing the base contract already holds — an article's single angle and the reader who may leave at any sentence, a report's question stated in its reader's terms with the answer before the evidence and every figure carrying its basis, a press release's news in the first sentence and its facts in a form a journalist can print. Each technique states its three-part arc as an editorial requirement rather than a template: ABT's settled situation, real contradiction, and the consequence that follows, and PAC's falsifiable premise, an analysis that tests it rather than illustrating it, and a conclusion that adds what the analysis earned. All five are language-independent and written in English, with examples meant to be applied semantically in the target language, and each carries a review extension in a `<name>.review.md` beside it holding only diagnostics, examples, edge cases, ambiguity resolution, and minimum-safe-correction guidance for the requirements its base half already states — so a Skill that only writes loads the base half and stops. The directory remains the only list of what is installed: adding a further genre or technique is still one file and no coordinated edit anywhere else, a name with no resource behind it is refused rather than resolved to the default, and a technique applies because it was selected and never because a draft resembles one (issue #104).
