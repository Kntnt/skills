### Added

- `docs/evaluation/records/` now holds the Unslop Skill's Claude-family record: the whole shared fixture corpus run against `/unslop` as a user of it runs it, with every outcome written in the protocol's format so the matching GPT-family run can be compared by reading rather than by re-running. Forty-nine invocations, each its own Claude Code turn with no memory of any other and its own throwaway copy of the corpus, with every side effect read from a checksum of the working copy taken before and after rather than from what the run said about itself, and with each run's own tool trace read as well — what a correction subagent was actually given, whether a returned correction was reviewed again, and what the run loaded before reading the text are the three things this Skill's contract deliberately keeps out of its output. The anti-slop pass caught the catalogue's seven patterns in both supported languages, on Swedish instances and on ten of the Swedish resource's own scope items beside them, which is the criterion the corpus could not stage before issue #142 added a Swedish slop fixture. Clean fixtures came back with the short no-change status rather than a rewritten text, in the artifact's own language where that language was Swedish. Nothing outside the lens was corrected: the mechanically flawed English and Swedish fixtures still carry every error they arrived with, no genre, technique, or structural expectation entered any run, an invocation naming a genre and a technique was refused rather than ignored, and no mechanical pass appears in any of the forty-nine traces. The Correction Budget behaved as the shared loop contract specifies at `0`, at the default, and at `2` and `3`, with a fresh subagent per correction carrying the complete current text and the complete current findings handed over directly rather than through a file, a re-reading after every correction rather than acceptance on the corrector's report, and all three stopping conditions on record — no findings with budget unspent, the budget spent with findings carried forward, and a round that made no relevant progress. Language precedence held at each of its levels, and a recognized `kntnt` map supplied the language without being created, completed, synchronized, or otherwise disturbed: a one-key map came back with one key, and a map naming a language the collection does not carry stopped one run as unusable metadata and survived a changed artifact intact when a flag superseded it. Output was exercised through the real Skill seam across the response default, a new file, an existing file, an existing directory, an ascending collision suffix that stepped past two occupants to `interview-notes-3.md`, a filename derived from a URL title, In-place Editing, unchanged results at three destinations, and eight documented refusals, none of which left a partial effect behind. No run remarked on source material it was not given, on any fixture, including the interview transcript and the long factual evaluation. Material the findings did not concern came through as it arrived: frontmatter, formatting, quotations, and code, the last of them on run-local material because the corpus carries no code at all, where a run that rewrote or cut the title and five paragraphs left a fenced Python block, an indented block, and two inline code spans byte-identical, down to a misspelling inside an exception message and two identifiers named after the very patterns it was hunting. Three real defects were found and filed rather than absorbed — a brief supplied inline was rewritten into a new article instead of being read against the catalogue (issue #147), nothing says whether a file-targeted run also echoes the artifact into the response (issue #148), and two invocations differing only in their Correction Budget disagreed about whether prose inside a code sample is a finding at all (issue #149) — the findings-report language gap already filed against Redline was recorded as reaching this Skill too (issue #145), and the corpus's want of any code material was filed as issue #150 rather than closed by adding to the corpus under the run that needed it. Nothing in the corpus, the protocol, or the criteria was changed to accommodate any of them (issue #111).
