`CHANGELOG.md` — under `## [Unreleased]`, in `### Fixed`:

- A run that delivers a Text Artifact to a file or a directory the caller named no longer repeats that text in the response: the response says where the text went, the derived filename included, and carries the findings the file cannot hold. Nothing had said whether a file-targeted run may echo the artifact, so it was decided per run — six of seven recorded `/unslop` runs that named a destination printed no text, and the seventh printed all four paragraphs of an artifact byte-identical to the source the caller already had. The rule holds whether or not the pass changed anything, so a run that writes an unchanged file does not become the one run that echoes. It is stated once, in the Collection Library's delivery contract, so every Skill that delivers through it inherits the answer. The response-targeted default is untouched, and so are the destination rules — path handling, overwrite semantics, filename derivation, and collision numbering (issue #148).
