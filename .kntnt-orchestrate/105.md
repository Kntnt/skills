`CHANGELOG.md` — under `## [Unreleased]`, in `### Added`:

- `/redline` reviews one supplied text against the Collection's editorial contract and closes with exactly one mechanical pass. It needs no Write provenance: a text this collection wrote, a text a person wrote, and a text produced elsewhere entirely are reviewed the same way. Genre, technique, and language each resolve independently by the shared precedence — the Formal Invocation, a recognised `kntnt` map in the text's own leading frontmatter, the current Contextual Instruction, applicable Conversation Context, inference from the text, then the default — so an explicit genre sits beside a language read out of frontmatter and a technique named in an instruction; genre defaults to `general`, no technique is ever inferred from a text that merely resembles one, and a materially mixed language is asked about rather than guessed. Handoff Metadata is never required and never created, a recognised map being used as defaults and then synchronised to the resolved configuration before delivery, while ordinary document frontmatter is never read as this collection's and an unusable recognised value no flag supersedes is reported as such instead of being read as the value it resembles. The review loads the base contract and its review extension, the selected genre and technique with theirs, the shared anti-slop catalogue, and the composition, review, and anti-slop scopes of the resolved Language Resource; mechanics are left to the closing pass, which resolves its own. Source material is outside the contract — the review judges what is in front of it, never asks for the material a text came from, and never remarks that source verification was unavailable, while a contradiction or an editorial defect visible inside the text itself remains an ordinary finding. `proofread` is then followed exactly once, with the resolved language supplied formally and only guidance relevant to mechanical correction forwarded, and nothing substantive follows it, so a later edit cannot put mechanical errors back. A clean run returns the resulting text alone, and a clean response-targeted run that changed nothing returns only the short no-change status in the text's own language; a run with findings left delivers the text to its Output Target and reports the findings separately even where nothing in the text changed, a file-targeted or in-place run leaving them in the response. The review's own working never reaches the output. One invocation processes one text, delivery follows the Collection's shared output contract including In-place Editing and its refusals, and `proofread` and subagents are declared as a Skill Dependency and a hard Capability whatever Correction Budget an invocation names. `--max` is that budget; this release accepts `0` alone, which is also its default, the correcting half of the Skill being a separate ticket, and a positive value is refused rather than quietly treated as zero (issue #105).
- The Collection Library now carries the two documents a review is read through. `references/editorial/base.review.md` is the base contract's review extension: diagnostics, worked ways of reading for each of its requirements, what does and does not count as a finding, and minimum-safe-correction guidance — no independent target, and no base rule restated. `references/editorial/anti-slop.md` is the collection's own condensed, language-independent catalogue of machine-sounding prose, covering false contrasts, empty openings, importance inflation, vague attribution, synonym cycling, robotic rhythm, and generic conclusions, each with what it costs the reader and the smallest change that removes it. It lives in the Library rather than under a Skill because more than one Skill applies that pass, its English examples are applied as semantic patterns in the target language while the words, phrases, punctuation, and constructions of one language stay in that language's own anti-slop scope, and it carries the upstream MIT notice inside the file, where a reader of an installed Skill actually receives it. No external Skill becomes a required or optional Dependency. ADR-0101 records why an adapted catalogue is owned rather than depended on (issue #105).
