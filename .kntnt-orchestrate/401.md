# Entries this ticket owes files the run writes

## CHANGELOG.md

Under `## [Unreleased]`, in `### Fixed`:

- `/redline` and `/unslop` now tell the fresh subagent that makes each correction where to put a file it writes while working. A subagent had written its candidate text to a fixed name in the scratchpad its session shared with a concurrent run on the same column. That run wrote the same name, and the subagent deleted the other run's repair as its own stale copy. Both correction briefs forbade writing the brief itself to a file, but said nothing about a file the subagent writes for its own purposes, and no caller can tell the subagent that, because the brief is all it receives. Each brief now has one paragraph, worded alike in both, that tells the subagent to keep such a file in a directory it created for this one round, with a name made unique when it was created, and to remove that directory before it returns, including on failure. The paragraph says that a fixed name under a shared temporary directory does not meet this, and describes the failure: another run working at the same time on the same text writes the same name, and the subagent destroys work that is not its own. In five Redline runs started together on that column in Claude Code on `claude-opus-5-5`, with one scratchpad shared by all of them, no run collided and every correction subagent used a directory of its own and removed it. Unslop was not run (#401).
