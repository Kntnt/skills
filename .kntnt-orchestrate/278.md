# Changelog entry for #278

## CHANGELOG.md

### Fixed

- Orchestrate now establishes that a run above `--at-once=1` can operate a ticket worktree before any ticket is claimed. A run at that concurrency builds each ticket in a worktree of its own, isolated inside the repository's common Git directory, and the session running Orchestrate may not issue Git commands there when the Harness holds it to its own worktree. The preflight conducts one read-only Git command that accesses the worktree infrastructure. Where that command is refused, the run reports the refusal, starts nothing, and names `--at-once=1` as the alternative, which builds on the branch already checked out and requires no worktree access. `help.md` says what a run does when the session cannot operate a ticket worktree (issue #278).
