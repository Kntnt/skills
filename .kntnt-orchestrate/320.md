### Added
- `/mirror` reruns incrementally. A second run into an output directory that holds an earlier run's manifest still discovers everything, but requests every URL whose row names a saved file still on disk, and for HTML and CSS its raw copy, with `If-None-Match` from the row's `ETag` and `If-Modified-Since` from its `Last-Modified`, whichever the row has. A `304` keeps the file and records the URL as `unchanged`, carrying the earlier validators, digest, size and content type forward so the next run is as conditional; an unchanged page or stylesheet is read for links and resources from its raw copy, and any other success replaces the file and its raw copy. The rewrite pass runs over every raw file, unchanged ones included, so a reference left absolute because its target was not yet in the mirror turns relative once it is, and writes a file only where its bytes differ, so unchanged files keep their modification times. A URL an earlier run saved that this run did not discover keeps its file and is recorded as `absent`; nothing is ever deleted from the tree. The manifest is rewritten whole each run and gains a `charset` field, the encoding the server declared, which a rerun decodes an unchanged page with. The report counts unchanged pages, files and resources and absent entries, and `--dry-run` against an existing mirror marks each URL it would request conditionally with `conditional` and still writes nothing (issue #320).
