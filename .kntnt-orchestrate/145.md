`CHANGELOG.md` — under `## [Unreleased]`, in `### Fixed`:

- A findings report is now written in the language of the Text Artifact rather than the language of the invocation, which is the answer the shared delivery contract already gave the short no-change status. Nothing had said which language such a report is in, so it was decided per run: two runs of `/redline` over the same Swedish text on the same day resolved `sv` and reported fifteen findings in Swedish in one and the same findings in English in the other, and `/unslop` split the same way with the polarity reversed. The rule is stated once, in the Collection Library's delivery contract, so every Skill that reports findings beside a delivered artifact inherits it — Redline and Unslop today, and any Skill added later without an edit — and both manpages now tell the reader the language of the findings beside the language of the status. Which findings are reported and how is untouched, and so is the no-change status rule (issue #145).
