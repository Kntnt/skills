- `/orchestrate report` works on the default branch again. It asked the tracker for every closed ticket carrying `ready-for-agent` or `orchestrated`, bounded only by the day the branch left the default one, so on the default branch the question was asked whole. Once 204 closed tickets carried `orchestrated`, the answer filled the tracker's page of 200, and every run on `main` ended with the report refusing. The run's state now records the UTC day of the first plan that writes it, and every later write keeps that day. On the default branch, `report` reads only tickets closed on or after it. On any other branch the fork-point bound is unchanged. A state with no start day, such as one an earlier release wrote, one written over a run file that survived without its state, or no state directory at all, still asks the whole question and refuses a full page as before. ADR-0227 records the bound and what it costs (#447).
