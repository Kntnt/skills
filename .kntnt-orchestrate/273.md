- The Manager reads every Skill's invocation through one engine. `kntnt.py invoke --here=<skill>` takes the invocation payload — everything the user typed after the Skill name, verbatim, however many lines — on stdin and answers in one of three ways: exit 0 with JSON carrying the command path, the flags with their values, the operands in order, the Contextual Instruction or `null`, and the dependency payload `check` prints with the Capabilities the agent still answers; exit 3 with the addressed manpage on an exact help form; and exit 2 with the collection's refusal — what was wrong in one line, the addressed page's `## SYNOPSIS` verbatim, and that page's own `--help` route — on an invalid form, or with `check`'s payload where a Dependency is Unsatisfied. In order it makes the dependency check `check --here` makes, splits the Envelope at the first standalone unquoted `--` exactly as the Library file states it, routes `--help`, `-h` and `help` and a command path's `--help` to the shipped page and refuses a Contextual Instruction beside one without rendering it, and holds the Formal Invocation to the grammar the Skill already ships — the `argument-hint` and the `## SYNOPSIS` and `## OPTIONS` of the most specific page a command path addresses — in the collection's one order: a token is command path exactly where a page under `help/` answers to it, a flag is declared exactly where the page names it and carries its value with `=` or stands bare where the page marks the value optional, and everything after the first operand is operand, so a Skill with no flag and no command path takes a dash-prefixed token as operand. It checks the form of the operands — present, absent, one, many — and never their meaning, and an empty payload is the bare form, valid exactly where the SYNOPSIS admits one. It reads no grammar through `library/scripts/argument_grammar.py`, whose permissive split belongs to the two engines that refuse in JSON. The suite runs the Library file's worked-cases table row by row, every shipped Skill's documented forms and refusals against its real pages, and the Manager's own verbs, so a grammar surface the engine cannot read fails the suite. No body calls it yet — the bodies move in the changes that follow — and no `SKILL.md`, manpage or README changed. `docs/rules/skills.md` states the engine's contract beside the checker's (ADR-0181).
