### Added

- The fixture corpus now stages the two situations it had no material for. `prose/slop-heavy-sv.md` carries the anti-slop patterns in concentration in Swedish — the shared catalogue's seven as they appear in Swedish, and beside them the items the Swedish Language Resource's own anti-slop scope names that English has no counterpart for: the Swedish empty openings and closings, the imported false contrast, the metaphor stock, superlative inflation, the comma after a fronted connective adverb that Swedish does not take, English punctuation carried across, the triad reflex, wholesale-translated hedging, and authority attributed to nobody. A run that finds no pattern in a Swedish text carrying none has not shown that it would find one, so until now nothing could say whether the catalogue reaches a language it is not written in. `frontmatter/handoff-partial.md` carries a `kntnt` map with one key over a body that alternates Swedish and English inside its paragraphs, so that one invocation settles the genre by flag, the technique by the map, and the language by a Contextual Instruction — the first three levels of the resolution order each settling a different parameter in a single run, which a complete map can never leave room for. Both carry an index entry in the corpus README's own five-field format, the partial map's naming which parameter each level is expected to settle so that an evaluator stages the case rather than deriving it, and the corpus suite now requires both kinds by name: the Swedish fixture is held to carrying at least twelve of the Swedish scope's own items, and the partial-map fixture to a map with at least one of the three keys and fewer than all of them (issue #142).
