CHANGELOG.md
### Removed

- `/model-selector update` is gone, and so is `catalogue.py adopt`. The daily catalogue pass already learns new models, per-category prices, thresholds, deliberation levels, release dates and aliases from its three structured sources, removes a model its maker stops listing, and resyncs the generated agent definitions, so the verb had nothing left to do that the machine did not already do. `help/update.md` is deleted and the Skill's grammar has no `update` path; `/model-selector update` is now ordinary work text, like any other word, rather than a refused form. `adopt` goes with its merge and plan helpers, the validator it shared with the pass stays, and `setup_apply.py` no longer syncs the definitions without a profile, since only `update` asked it to. Subscription plans are now read from the shipped seed alone and change with a release of the collection, which `/kntnt update` brings in: `catalogue.load` ignores plans an older `catalogue.json` still carries, `status` no longer reports the plans' `retrieved` dates, and a plan the catalogue does not hold is noted as such with `/kntnt update` named. `provider_says`, a provider's own one-line description of a model, is removed from the seed, the loader and the printed catalogue, since nothing ranked on it and prose never becomes a number. `setup` reads no web page: it no longer opens by reading providers' pages when the catalogue is thirty days old, and it ends by running `catalogue.py refresh` once, whether the profile was written or the review declined but not after a refused one, and reports what each source said. Started by hand, that pass takes the pass's lock and ignores the daily marker, so setup refreshes even on a day the daily pass already ran. The header of every generated agent definition names the daily catalogue pass and `setup` as what rewrites it. `docs/rules/routing.md`, `SKILL.md`, `help.md`, `help/setup.md`, `help/status.md`, `help/objective.md`, `help/reset.md`, `references/setup.md` and the README say so, and ADR-0194 records the retirement and where each part of the old `update` went (issue #313).
