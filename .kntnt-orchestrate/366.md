CHANGELOG.md

- A delegated run now inherits the permission level of the session that started it, so a builder started through a bridge command can commit, reach the network and use the package cache without its caller editing the command it was handed. The launch planner no longer picks a sandbox of its own: a caller passes `--permissions=<level>` — `bypass`, `auto`, `edits`, `never-ask`, `manual` or `plan` — and each level reaches Claude Code and Codex in that tool's own spelling, while naming no level produces a command with no permission flag at all, leaving the started tool at the user's own configuration for it. A request saying the work writes nothing still gets a start that cannot write, an unknown level is answered as silence with a note naming it rather than refused, and Orchestrate carries the level from its session into every routing call of a run (#366).
