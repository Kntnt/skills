# Entries this ticket owes files the run writes

## CHANGELOG.md

Under `## [Unreleased]`, in `### Fixed`:

- `/orchestrate`'s ticket and repaired verdicts now prove a load flake before they fail on one, as the wave check already did. A verdict that sees a strict subset of tests fail reruns exactly those tests three times in isolation on the unchanged head, with the gate command's own selection syntax, and three passes earn one complete rerun of the gate on the same head. A green complete rerun counts that command as passed, and the verdict passes, naming its flake evidence, only where every acceptance criterion is met as well; an isolated failure or a second complete failure is a fail that quotes the evidence. The verification brief had forbidden that rerun, so a test that failed only while several suites ran at once failed its ticket: in one unattended run it spent a ticket's first amend on an amend that changed nothing, and cost the run about 25 minutes. The protocol is now one paragraph worded alike in all three verdict briefs, and every amend verdict carries it. The orchestrator records the flake any verdict proves, and `run.py flake --ticket=<number>` records a ticket's flake against the branch and head of the working tree the run has open for that ticket, rather than against the run branch's head, and refuses, recording nothing, where no such tree is open. The final report says which verdict established each flake (#422).
