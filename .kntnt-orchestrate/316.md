### Added
- `/mirror` saves a web page to disk with everything it needs to display, so that it opens in a browser with nothing fetched from the network. It follows the URL's redirects to the start page and fetches, one request at a time, the page's images including `srcset` and `picture`, stylesheets, scripts, fonts, video, audio, posters, tracks, icons, preloads, the web manifest, and what `iframe`, `object` and `embed` show, together with everything a stylesheet or a `style` attribute references through `url()` and `@import`, whatever host it is on. Every reference in the saved HTML and CSS that points at a file in the mirror is rewritten to a relative path, and every other reference is left as an absolute URL; `base` elements are honoured and then removed, and an `integrity` attribute is removed only where the rewrite changed the bytes it guards. The tree holds one directory per host with each file at its URL's path, and the manpage states the mapping: a directory URL is `index.html`, an extensionless HTML page gains `.html`, a query string stays in the name before the extension, the characters a file name cannot hold are percent-encoded, and a file whose path another URL needs as a directory takes `index.html` or `~file`. HTML and CSS are also kept as served under `.mirror/raw/`, and the run writes `.mirror/manifest.ndjson`, one row per URL with its outcome, and `.mirror/run.log`. `--output`, `--resources=all|in-scope|none`, a repeatable `--header`, `--user-agent` and `--dry-run` are the flags; the engine exits 0 when everything was fetched, 1 when something failed, and 2 on a refused value. It is the first Skill of the `web` Category, and its engine takes `httpx`, `selectolax` and `tinycss2` through its PEP 723 block. ADR-0196 records why the engine owns fetching, the URL-to-path mapping and the rewrite, and why wget and httrack were rejected (issue #316).
