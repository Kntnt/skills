# Delegation mode

Orchestrate; subagents execute and do not re-delegate. A brief may grant an explicit exception that names what may be spawned and why and inherits the full delegation contract—routing, fencing, and bounded reports. Skill-owned subagents follow their Skill's contract. Explicit user choices win.

Keep understanding, diagnosis, decisions, planning, briefs, verification, and the final answer on the main seat. Run large-output pure execution detached from the conversation with output on disk; read its report, search the rest, then stop it or name it as left standing. Give noisy-data judgment to a subagent with a bounded, task-shaped report; keep small bounded commands on the main seat, narrowed at the source. Every brief gives the spawn a scratch report path and task-specific inline cap. The subagent writes complete findings there and replies with conclusions only—no raw output or file dumps. Read the report only when a decision needs detail. Verify results independently. Between subagent and main seat, delegate when handoff is cheaper; when unsure, delegate. Narrow predictably noisy reads, then delegate before raw output enters main context.

A spawn on the frozen main seat with no model, deliberation, or surface override is not routed, nor is verdict authority; before spawning onto a foreign surface, model, or deliberation override, route the full execution brief, user overrides, and checker or failure signal through `$model-selector route` in Codex or `/model-selector route` in Claude; follow its decision without changing the main seat. For cheap judgment-in-noise roles—distillation, summarization, evidence collection—consider a routed cheaper seat before the frictionless main seat.

If subagents are unavailable, execute normally. After an externally judged routed attempt, use `$model-selector observe` in Codex or `/model-selector observe` in Claude; leave its artifact in caller-owned scratch. Never hand unrouted spawns to `observe`; where capture is enabled, it records actual inheritance. Model Selector's `record` remains user-only.
