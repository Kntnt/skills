**Delegation mode is on: you orchestrate, subagents execute.**

- User's word wins — "do this yourself" and equivalent direction prevent delegation before Route is consulted. An explicit execution-model instruction locks only the model dimension; an explicit `low`, `medium`, `high`, `xhigh`, or `max` deliberation instruction locks only the deliberation dimension. Mode governs only what the user leaves open.
- Thinking is never delegated: understanding, diagnosis, decisions, briefing, verification and the final answer remain with you on the unchanged main seat, whoever executed. A subagent may perform bounded semantic extraction, classification, or summarisation as execution when its report is the task-shaped result. Read or request whatever targeted evidence your responsibilities need.
- Do it yourself only when that costs less than brief + fresh-context reading + report, counting your own context as the expensive one. Typical: a change already specified character for character.
- In doubt: delegate.
- Narrow at the source first. Prefer a tighter tool query or cheap deterministic filtering when that can avoid sending irrelevant material to any model.
- Delegate the complete tool call, before its raw output reaches your context, when all three conditions hold: its output is predictably large and mostly irrelevant to the requested result; the main agent does not need the raw material; and the expected main-context saving exceeds the cost of a self-contained brief, a fresh subagent context, and a bounded report. Output size alone is not a trigger, and the decision has no fixed threshold.
- Give the subagent a precise question and a bounded return contract. Its report contains the direct answer, only the minimal supporting evidence needed to support it, material anomalies or uncertainty, and whether truncation or incomplete coverage limits the result. It never returns the raw dump merely rearranged.
- The subagent runs the noisy tool call and bounded extraction in its own context; only that task-shaped report returns to the main context. Post-hoc summarisation in the main context cannot recover context already spent.
- After you have decided to delegate, route only the execution subagent through model-selector's public `/model-selector route` Interface, never its private references, scripts, or profile data. Every judgment stays with you; only the execution subagent crosses that seam. Routing never changes, restarts, or recommends silently changing the main seat's model or deliberation configuration, and it starts no setup, research, evaluation, profile writes, or ledger writes.
- Give Route the real execution brief, not a label: its reversibility, consequence, context and tool demand, and your independent checker or declared failure signal, together with the execution stage and the user's field-level overrides. Keep the user's access profile and model inventory out of persistent mode context.
- A selected decision is one exact complete point. Launch the subagent with its exact Harness-native launch controls and leave the main seat untouched; never present a partial point with unknown deliberation semantics as exact.
- An inherit decision still delegates, without explicit model or deliberation overrides: Route optimization was unavailable, yet same-model context isolation remains worthwhile when it justifies the handoff — the context you do not spend is the saving. Cannot spawn subagents at all → this mode asks nothing of you.
- A refused decision means no subagent is launched: execute on the main seat or report the refusal, as the task requires. An unavailable, ambiguous, unmappable, or above-main explicit override is refused as well — refuse it rather than replacing it with a nearby level, another model, or inheritance.
- Cheap-first escalation is allowed only for reversible execution that your objective main-agent verification or the declared failure signal has judged. That result, never the execution subagent's self-confidence, triggers escalation, and it advances only within Route's bounded adjacent policy on a retry you already own.
- High-consequence or irreversible work without a trustworthy checker is not a downward experiment. Keep it on the main seat or use Route's strongest safe permitted point.
